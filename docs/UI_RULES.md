# 共用 UI 規則

此頁只持有跨畫面的互動原則。工作區位置／手勢只改 [WORKSPACE_REVISION](WORKSPACE_REVISION.md)，各媒體規則改專項文件；[畫面索引](UI_SCREEN_CATALOG.md) 用於找入口。現有三套主題與共用 UI 規則已定；品牌／專屬字型延後。

## 保存、焦點與狀態

- 設定／編輯提供保存與取消；保存中防重複提交，成功才標示已保存並更新畫面。失敗保留草稿、原因及重試入口。
- 有草稿離開時提供保存、捨棄、繼續編輯；ESC／X 不靜默丟稿。一般選取、切模式或看圖片不增加確認窗。
- 彈窗／覆蓋層接收焦點，關閉後回觸發控制。ESC 一次只處理最上層：彈窗／Drawer、媒體覆蓋層／全螢幕、工作區放大；不要同時關多層。
- 圖示有可存取名稱及 Hover／聚焦 Tooltip；有快捷鍵時一起顯示。輸入框、選單及中文組字不攔截成閱讀／導覽快捷鍵；主要操作可用鍵盤抵達。
- 選取、錯誤、停用不能只靠顏色；停用有原因。區分無資料、未知、不支援、離線、尚未索引、執行失敗，不將缺值佔位寫回真實資料。
- 表單錯誤靠近欄位；執行失敗保留可查看的原因，不能只依賴短暫通知。長工作顯示進度／取消及部分結果，不把部分失敗報為全部成功。
- 操作回應以 `notice: { level, message }` 明確區分 success／warning／error，不以文案或語言猜測等級。部分完成顯示警告，全部失敗及拋出的例外顯示錯誤；專案名稱等使用者內容不能改變等級。成功提示約 5 秒收起，警告／錯誤不自動收起，可手動關閉或由後續操作更新；文字標題及可存取角色一併區分，不能只靠顏色。通知不寫入可攜記錄。
- 側欄移除／取消連結、刪群組、清理受管資料是不同操作；清理必走 [儲存規則](STORAGE_OPTIONS.md) 的預覽與範圍確認。

## 共用呈現基線（可調）

沿用 Mantine 與共用樣式，不增加第二套表單／按鈕方案。同類間距、控制及捲軸一致；長名稱／路徑可省略但可查看全文，編輯時不截斷。圖片等比，過寬表格在自身區域捲動，不能撐寬整個應用或遮住視窗控制。拖曳標題列不得吞掉按鈕與輸入。

### 全域外觀與語言

應用程式設定位於右上角全域標題列、視窗控制左側，首頁、未開專案及收起專案欄時均可使用；專案選單仍只管理該專案。設定內「外觀」集中主題與介面語言，「連結與維護」保留原本重新連結／匯入／清理入口。

「瀏覽」區塊承載全域操作偏好；自動開啟右側內容規則由 [工作區](WORKSPACE_REVISION.md#導覽時自動開啟內容2026-10-28) 持有。

主題提供深色經典、霧白玻璃（白色半透明面板／柔和藍色／模糊）、暖紙墨橘（米白／墨色線條／橘色），參考使用者兩張圖的風格，不採用圖稿中的舊產品結構。玻璃感使用應用內部 CSS 層次，不要求作業系統視窗透視。所有專案使用同一主題，無個別專案覆寫。

2026-10-28 已確認後續整理方向：延續三主題與共用 SVG，優先統一字級、間距、焦點及禁用狀態；字型採系統字型與語系適配。品牌命名與專屬字型延後，不重開三主題選擇。此段是後續品質方向，未表示本次已完成全介面查核。

介面支援繁體中文、日文、簡體中文、英文、西班牙語；尚無語言偏好時依系統語言對應現有五語系，無對應時英文；已有偏好保持原選擇。主題缺省維持暗色。主題與語言可立即預覽，一起保存；取消或確認放棄後回復已存設定。保存失敗保留草稿及重試入口。兩者只存本機 `workspace-ui.json`，可攜 schemaVersion 維持 1。專案／資料夾名稱、欄位值、使用者自訂標籤與外部來源內容不翻譯；檔案系統、外部來源及後端技術診斷保留原文，供追查。

內建透明 CELL 的中性預設文字色跟隨主題；其他明確自訂文字色及背景色原樣呈現，不改寫既有版面。內建模式／設定用語依選定語言顯示，繁體中文採「卡片／表格／樹狀圖／組件」；使用者輸入後置替換，避免翻譯資料名稱。操作圖示集中在 `src/icons.tsx`，沿用 20×20、1.6 線寬、圓端點 SVG，不依賴字型符號或 Emoji 顯示；可存取名稱與 Tooltip 跟隨語言。

實作入口：`shared/themes.ts`／`shared/locales.ts` 定義穩定 ID；`src/themes/` 持有配色及預覽狀態；`src/i18n/messages.json` 持有介面翻譯，資料名稱不作動態全文替換。驗證入口為 `tests/appearance.test.ts`、`tests/workspace.test.ts` 與 `tests/appearance-ui.ts`。

2026-10-28 本輪驗證：build、完整資料測試 76 項、最後變更後的 appearance／workspace 10 項及完整工作區 UI 通過；外觀專項 UI 涵蓋三主題的 CARD／TABLE／TREE、閱讀器／資料夾設定、五語言保存重開與原生確認文字、取消預覽、隱藏側欄、800px 與原始媒體保留。截圖在 `.test-output/appearance-9OLUTV/screens/`。閱讀器既有的閱讀偏好保存獨立比對，主題／語言切換不更改資料夾記錄。原生 Mac 執行環境未執行。

密度、色碼、字型、圓角、陰影及窄視窗切換點皆非產品定案；實際值查 src/style.css／元件，避免另維護數值表。原 UI-R01～05 的候選尺寸、窄視窗覆蓋方案與尚未採用細節保存在 [原稿](history/agent-docs-before-cleanup.md#ui-rules)，不因整理而視為已批准／已實作。

修改幾何或焦點時才檢查受影響的窄視窗、長中文／日文名稱與顯示縮放；一般文案不例行重跑所有尺寸。快捷鍵實際支援依各元件／媒體規格，不把建議鍵位宣稱全部已交付。

## 共用閱讀器操作

漫畫與圖片閱讀器共用以下核定互動；各自縮放基準、配對及內容範圍仍由專項文件持有。回報問題與實作差距見 [工作清單](WORK_ITEMS.md)。

- 放大／縮小按鈕的完整範圍皆可點擊，僅真正達縮放上下限時停用；重設縮放提供快捷鍵及 Tooltip。快捷鍵為 R，輸入、選單與中文組字不攔截。
- 導覽箭頭左右位置與圖示固定；各方向的提示、可存取名稱、點擊動作及鍵盤意義一致。有閱讀方向設定時，左至右為左上一頁／右下一頁，右至左為左下一頁／右上一頁；只在對應序列首末停用。右箭頭亦須能正常點擊，不以圖示位置寫死上一頁／下一頁。
- 頁碼 SELECT 的數字、箭頭、內距與邊緣皆可開啟下拉，不要求精準點數字；選頁後焦點回閱讀區，保留鍵盤選取與翻頁。

## 共用媒體生命週期

新媒體工作區的列表／大視窗分工與同資料夾佇列由 [工作區主規格](WORKSPACE_REVISION.md#統一媒體工作區) 持有；下列進入資料夾播放第一支是既有影片分類行為，不套入新混合瀏覽頁。共用停止／釋放、動畫與受控來源要求仍有效。

漫畫／相簿共用圖片與縮圖能力，版面分開；可見範圍才播放 GIF，閱讀／圖片覆蓋層開啟時停止背景動畫。不加未核定的固定播放張數上限。影片同時一個來源，離開／隱藏時停止或暫停，接續播放預設關閉、可由專案明確啟用並取消倒數；進入資料夾從頭播放第一支，點選縮圖也播放；移除續播提示與觀看位置紀錄；字幕載入失敗保留原字幕。控制欄與接續限制見 [影片](VIDEO_VIEWER_DESIGN.md)，支援格式與空值規則由各媒體文件持有。

## 浮層一致性

Drawer／Modal 的背景由容器與全域主題統一持有，header、body、footer 不各自設定異色；玻璃主題避免半透明背景重疊加深。透明標頭採一般文件流，長內容不從標題背後穿過；維持 ESC、關閉及焦點操作。
