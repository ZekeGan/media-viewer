# 視覺風格選擇

這三份稿使用相同媒體清單，方便比較色彩、密度與收藏感。尚未套入正式介面；選定後再整理成可重用的 Mantine 主題與 CELL 預設樣式。

可用瀏覽器開啟 [互動比較稿](design/style-options.html)，點上方 A／B／C 切換。

| 方向 | 視覺與適用情境 | 實作成本 |
| --- | --- | --- |
| **A 清爽工作台（推薦）** | 淺灰綠、清楚的工具區、適中留白；適合長時間搜尋、整理與編輯。 | 低，最容易沿用 Mantine。 |
| B 深色媒體庫 | 深灰藍與淡紫、大封面；適合遊戲／漫畫／影片收藏。 | 低至中，需要處理 CELL 自訂色彩在深色底的對比。 |
| C 紙感收藏冊 | 暖白、棕色、細框與紙張感；偏向私人書架和相簿。 | 中，需要較多細部樣式。 |
