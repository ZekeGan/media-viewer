# 工作區現行規則

此頁是外框、專案建立與三模式互動的主文件；依 C-87～C-92 使用者指示整理，C-93 記錄實作交付，並不代表使用者已查收。舊圖稿及歷次改法見 [決策帳本](DECISIONS.md)／[整理前原文](history/agent-docs-before-cleanup.md#workspace-revision)，不需每輪載入。

## 外框與專案區

- 頂部產品名稱移除，只留 Logo 與搜尋入口；搜尋範圍 SELECT 僅在搜尋跳窗內。搜尋預設／語法見 [搜尋規格](SEARCH_DESIGN.md)。
- Logo 下方工具列保留首頁 ICON；應用程式設定移到右上角全域標題列、視窗控制左側，含統一主題與語言，以及本機重新連結、匯入與全域清理。各專案選單內另有「專案設定」，不混在全域維護中。外觀保存與語言規則見 [共用 UI](UI_RULES.md)。
- 「我的群組」包含最愛、使用者自訂群組與未分類；最近新增已移除。專案未加入自訂群組才列未分類，收藏狀態獨立。當前一個專案的自訂歸組與排序由本機設定保存。
- 群組拖曳標題排序，以目標標題上／下半部決定插入前／後並顯示插入線；移除選單上下移動按鈕，鍵盤可用 Alt＋↑／↓。群組內專案沿用拖曳排序／移動。
- 群組與專案操作平時隱藏，僅該標題／項目 Hover、鍵盤聚焦或選單開啟時顯示；選取專案本身不讓操作常駐。自訂群組提供改名 ICON 與選單入口；最愛／未分類維持固定名稱。展開箭頭用名稱右方的圖示，隨收合狀態旋轉。來源：使用者本輪側欄修正及參考圖。
- 新增專案位於側欄最下方，用中性色；側欄可調寬、收合及捲動。群組內不設高度門檻或獨立捲軸；整欄仍可捲動，但隱藏捲軸外觀。右下角只保留錯誤、部分失敗與掃描進度；一般保存／切換不跳成功通知，來源匯入及資料夾清理結果留在操作頁。

## 建立與既有專案

建立順序：**名稱 → 分類 → 選資料夾 → 群組 → 完成**。群組預設未分類。資料夾先由原生選擇器選定，最後完成才開始建專案／掃描；取消不建檔。main 使用暫時選取憑證，renderer 不能任意指定未授權路徑。

新專案不再預建 TITLE／文字欄位，預設只含名稱、路徑與開啟資料夾組件；既有欄位及資料不因升版刪除。新專案預設掃描全專案；遊戲邊界仍生效。既有有限掃描專案保留原涵蓋範圍，只能由明確的擴大掃描動作新增記錄。調 CARD 顯示或導覽不默默掃描／初始化資料。

## 中央版面與工具列

中央與右側是同層、互相獨立的內容區，右區使用完整可用高度，不嵌在中央內容卡片內。

1. 第一列中間選 CARD／TABLE／TREE；資料夾 CARD 的方案 SELECT＋相連編輯按鈕與模式選擇同列。方案及卡片顯示設定只在「資料夾＋CARD」出現，切成檔案模式即隱藏，即使保存的資料夾模式仍為 CARD。共用動作包含重新掃描，「目前資料夾設定」ICON 放最右。
2. 第二列保留返回／前進與可逐層點擊的 Breadcrumbs，顯示路徑、筆數／層級等必要狀態。不重複專案名稱、根／父層按鈕、搜尋框或放大瀏覽按鈕；批次編輯暫不放工具列，資料 API 保留。
3. 其餘空間完整給 CARD／TABLE／TREE；CARD 分頁放內容底部。預設 CELL 背景透明。

## 三模式與開啟行為

| 模式 | 顯示範圍 | 雙擊左鍵 |
| --- | --- | --- |
| CARD 多層 | 同一畫面平鋪 ROOT 與其子資料夾；全部或 ROOT＝第 1 層至 N 層 | 保留中央範圍，更新共用目前資料夾與右側，不縮成子樹 |
| CARD 單層 | 初始顯示指定 N 層；進入後顯示該資料夾的直接子層 | 進入子層並更新右側，返回／前進同步 |
| TABLE（LIST） | 從 ROOT 開始，按目前所在資料夾逐層列出直接子資料夾 | 進入子層並更新右側 |
| TREE | 已建立且允許的完整階層可逐支展開，不受 CARD 顯示／分頁設定影響 | 更新共用目前資料夾及右側，保留整棵樹並定位該節點，不孤立成單節點 |

TABLE 可拖曳欄標題調整順序（或 Alt＋←／→），欄寬、排序與欄位身分維持獨立；順序依專案存於本機，移除的欄位忽略，新欄位附加於末尾。

所有模式提供以反斜線分隔的 Breadcrumbs；點祖先時更新共用位置與右側內容。Breadcrumbs 只回到目前位置的祖先，返回／前進維持瀏覽歷史，可回訪跨分支位置，因此先保留兩者。TABLE／CARD 單層點祖先會同步更新中央與右區；三模式共用目前檢視資料夾與返回／前進歷史，切換模式不恢復各自舊路徑。TREE 保留全樹並定位同一節點；CARD 多層保留專案範圍並定位同一卡片，單層／TABLE 顯示目前資料夾子層。

TREE 節點可收合／展開子資料夾；收合分支不加入 Dagre／React Flow 的節點及邊，非只用 CSS 隱藏。狀態依專案存本機，跨模式定位時只展開所需祖先。可調實作基線：初始顯示前兩層，同層超多時先收合該根；提供全部收合／重設展開，不改可攜資料或掃描範圍。

單擊維持選取；右鍵開啟獨立的資料夾設定 Drawer，與右側內容不同層級。TREE 初始佈局與點擊不可因延遲 fit 產生跳位，選取不應重算 Dagre。

所有開啟／進入先由 main 驗證實際路徑、有效記錄及保護邊界，成功才改導覽歷史／右區。缺失、損壞、停止建檔或受遊戲邊界保護時提示「未建立」／「無法建立」，不進入、不自動補建；有效遊戲 ROOT 本身仍可開啟。早期唯讀繼續 API 不代表可繞過此規則。

## CARD 專屬控制

- 專案設定原本的「顯示模式／每列筆數／每頁筆數」移到 CARD 工具列設定區，TABLE／TREE 隱藏。範圍模式／層級及每列／每頁密度直接排列在 CARD 工具列，以套用保存草稿；層數只列目前已掃描範圍的實際深度，不假設有 50 層，也不為取得深度額外掃描。
- 同一區兩項顯示控制：多層／單層，以及層數；多層可選全部或 1～N，單層選 N。每列筆數依可用寬度自動減少，每頁筆數獨立。
- 方案 SELECT 與編輯按鈕指向同一個作用中方案。版面只影響呈現，不更改欄位原值或掃描涵蓋。舊專案只有原版面也可開啟，不強制遷移自訂 CELL 樣式。

### 設定入口圖示區分（2026-10-28）

CARD 範圍與密度已直接顯示，不再使用滑桿 ICON／彈窗。工具列最右維持資料夾設定圖示；右側標題列亦提供同一設定入口，Alt+Enter 開啟目前資料夾設定。TABLE 提供可搜尋的欄位勾選選單，名稱必留，其他欄位可隱藏／恢復預設；顯隱、排序與寬度為獨立本機偏好，不改欄位資料。檔案模式的範圍資料夾、子層範圍、展示、類型與重新整理整合到上方工具列，寬度不足時分組換行。

## 右側內容與覆蓋層

舊分類定義與適用中央檔案／單檔預覽保留讀取相容；圖片／影片／音樂／其他的資料夾內容已共用媒體頁。新版分工與影音背景播放由 [統一媒體工作區](#統一媒體工作區) 持有，以下分類舊配置僅適用尚有呼叫的相容路徑，不能覆蓋共用新頁規則。

- 共用「返回頂部」固定於右側內容區右下角，只在目前內容可往上捲動（scrollTop > 0）時顯示；到頂、無捲動內容或內容切換後重新判定。只回捲該窗格，不捲整個應用；漫畫 TOP 也沿用此規則。

- 右側預設開啟並顯示 ROOT 內容；顯隱、目前對象及尺寸保存在本機設定。顯隱開關位於最上方全域工具列，沒有可瀏覽專案時隱藏；X 關閉與頂部切換狀態一致。
- 資料夾設定預設顯示一般欄位；改為「資料／圖片（選用）／來源匯入／進階」分頁，遊戲另有操作設定。移除更改內容資訊版面入口；私有覆寫、完整屬性／來源與清理均在進階頁。清理預覽、取消、確認及逐項結果直接留在此頁，沿用 token／指紋檢查，不開第二個彈窗。外側仍標示目前正在編輯共用或僅本專案資料，保留切換草稿保護。
- 資料夾內容依屬性切換；各類解碼與專用操作由專項文件持有。舊影片的播放器／檔案列上下配置只作相容呼叫規則，共用頁右側為檔案列表，明確開啟後由全域播放器接手。
- 設定 Drawer 的未保存變更受關閉保護；ESC 只退出最上層可關閉區域。工作區／閱讀器放大可用 ESC 退出。
- 所有捲軸採共用風格；焦點、快捷提示與保存規則見 [UI_RULES](UI_RULES.md)。沿用現有三套主題；品牌／專屬字型延後。

### 導覽時自動開啟內容（2026-10-28）

在全域「應用程式設定 → 瀏覽」提供「自動開啟資料夾內容」開關，說明為「進入其他資料夾時，自動展開右側內容面板」，預設關閉。這是所有專案共用的本機操作偏好，保存於 `workspace-ui.json`，不寫入可攜資料或個別專案設定。

- 關閉時，進入資料夾不強制展開右側；右側原已關閉則保持關閉，原已開啟則保持開啟並更新目前資料夾內容。
- 開啟時，成功進入／切換目前資料夾後自動展開右側並更新內容；驗證失敗仍沿用既有不進入規則。
- CARD／TABLE／TREE 的雙擊、Breadcrumbs 及返回／前進遵循同一顯隱規則，各模式原有中央導覽範圍維持不變。
- 全域工具列保留右側顯隱 ICON，與右側 X 一致；手動開關面板不改寫此自動開啟偏好。

## 檔案總覽

本節描述既有分類的中央跨層檔案模式。新媒體工作區改採右側檔案瀏覽，依 [統一媒體工作區](#統一媒體工作區)；既有跨層範圍／偏好在確認轉換前保留，不直接改寫。漫畫的檔案入口依 [漫畫專項](MANGA_VIEWER_DESIGN.md#漫畫檔案模式入口) 調整，列舉能力共用不代表各分類都顯示同一入口。

來源：使用者希望在 A 資料夾觀看 A 本身及所有子資料夾的檔案，C-103／C-105 採用檔案總覽方向，2026-10-29 再核定漫畫／圖片統一檢視。本節持有目標規則，既有實作與新增統一需求的差距見 [當前工作](WORK_ITEMS.md)，不以舊驗證推定新行為已交付。

### 需求與展示

- 新增「檔案總覽」方向，彙總目前資料夾與後代檔案；切到較小分類時，觀看範圍隨目前資料夾縮小。原資料夾結構與使用者整理方式保留。
- 展示使用中央工作區，與既有卡片／表格／樹狀圖的資料夾展示並存；右側供單一檔案預覽。檔案範圍獨立於 CARD 的顯示層數／分頁，切換展示不擴大專案掃描或初始化記錄。
- 提供「目前資料夾／包含所有子資料夾」的範圍選擇；每個檔案保留來源路徑，以便辨認跨目錄同名檔案及回到來源。分組時 A 自身的檔案也需呈現，不只列子目錄。

| 展示 | 畫面與用途 |
| --- | --- |
| 平鋪縮圖 | 把範圍內檔案集中排列；圖片／影片縮圖、其他檔案圖示，每項附來源資料夾。適合從大分類觀看整體。 |
| 依來源分組 | 同一範圍按來源資料夾分段，標示來源路徑與該組筆數，保留分類感。 |
| 完整路徑清單 | 以名稱、來源資料夾與類型列出，適合混合檔案及辨認同名檔案。不是把既有資料夾 TABLE 的列直接改成檔案。 |

漫畫、圖片／相簿及影片的檔案檢視共用列舉、範圍控制、排序／篩選與來源定位；選擇「包含所有子資料夾」時，漫畫也呈現允許範圍內的子資料夾圖片，不因分類默默排除。初次檔案總覽沿用平鋪縮圖及包含子資料夾的預設，可切來源分組／完整路徑清單，保留逐專案明確偏好。漫畫圖片保留來源作品歸屬，點圖進閱讀器時維持該作品頁序／配對，不把不同漫畫串成一本；來源分組可用於辨識作品。

其他檔案先顯示基本資訊與「開啟所在資料夾」，執行檔沿用明確啟動流程。中央工具列提供「資料夾／檔案」切換；既有專案保留原資料夾模式，初次開啟檔案總覽採上述預設。本機 browse 保存 contentMode、filePresentation、fileScope、fileRootId，不修改三種資料夾模式的語意。ZIP／CBZ 與 PDF 可再開啟 [文件檢視器](DOCUMENT_VIEWER_DESIGN.md)。

### 範圍、資料與生命週期

- 第一版只彙總專案已納入且允許瀏覽的範圍；若深度或排除規則使結果不完整，要明示「目前已納入範圍」，不能把部分結果稱為全部。超出此範圍的唯讀列舉方式另行設計，不默默擴大掃描或寫入。
- 沿用遊戲／App 保護邊界、排除規則及連結安全限制；不為觀看搬移、複製或刪除原檔，也不把 `.media-viewer` 內容列作一般媒體。
- 同名不同來源的檔案需有不同身分與存取授權，播放、字幕來源及個別檔案設定維持原檔歸屬，不集中寫到被選取的大分類；彙總不改資料夾身分、共用值或私有覆寫。
- 大量檔案先顯示首批、後續分批載入，縮圖按需載入並沿用既有效能方案。尚未列舉完成時顯示已找到筆數／載入狀態，不捏造總數；穩定排序與來源分組不得因批次回傳而跳動。
- 切換資料夾、範圍、模式或關閉內容時，取消／忽略舊請求，釋放舊預覽與播放；部分目錄權限失敗、檔案搬移／消失及縮圖失敗要能標示未完成／略過項目，不將錯誤顯示為沒有檔案，也不讓舊結果混入新位置。

### 實作與驗收

使用受控資料樹覆蓋 A 本層、深層子目錄、空目錄、同名檔、混合圖片／影片／其他檔、單一與多個來源；驗證三種展示的範圍一致、來源定位及資料夾導覽不變。另覆蓋漫畫檔案可跨來源彙總但閱讀不跨作品、影片／字幕歸屬、既有偏好、有限深度／排除／遊戲與 App 邊界、連結／權限失敗、分批取消與快速切換、大量檔案、窄視窗、五語言與主題。原檔與記錄不得因彙總檢視被新增、搬移或清理。

main 的 overview 只列出目前快照內有有效記錄的同專案資料夾，逐批重驗保護／路徑，游標綁定根身分與範圍。每批最多 200 檔案、8 個來源讀取批次；renderer 分批載入並以虛擬列限制 DOM；捲動事件先讀取純數值位置，避免延後更新引用失效事件而卸載整個介面。空白提示以篩選後結果判斷。預覽以來源 rowId／檔案 ID 讀取，不把彙總根當成來源資料夾。舊請求結果在離開／換範圍後忽略；檔案讀取與右側內容分頁不互相撤銷。驗證入口 tests/decided-media.test.ts、tests/decided-ui.ts；tests/file-overview-ui.ts 以圖片／影片各 1,200 檔驗證分批載入、密集捲動、三種展示、篩選、視窗尺寸及重新整理，確認可視區有卡片、DOM 有上限、原檔及可攜記錄不變。實際收藏未掃描。

## 檔案顯示與隱藏規則

預設隱藏作業系統標記 Hidden／System 的檔案，提供「顯示隱藏檔案」開關；點開頭名稱另設顯示選項，不與系統屬性混為一談。`.ini` 只是副檔名，不能整類排除。應用自己的 `.media-viewer` 與快取仍一律不列入一般檔案，開關不能暴露它們。

這是展示過濾，沿用既有掃描與搜尋契約，不新增掃描排除、不刪除或改名原檔、不改系統屬性。切換可見性會影響新建立的檢視佇列，既有搜尋結果仍受原授權／保護邊界約束；跨平台屬性讀取能力及讀取失敗必須驗證，不把查詢失敗當成空資料夾。偏好存本機，不改可攜檔案資料。

- 右側標題列在「資料夾設定」旁提供「前往此資料夾」ICON，指向右側目前正在展示的資料夾；各子來源的前往操作沿用相同規則。按應用程式內導覽設計，沿用同一進入驗證、目前位置與歷史；不混同另開檔案總管。按鈕具 Tooltip、可存取名稱及鍵盤入口；受保護／未建立的目錄不可藉此進入或初始化，停用時說明原因。已在目前位置時不重複追加歷史。
- 新版右側保留「目前資料夾／包含子資料夾」範圍選擇，初次預設目前資料夾；只彙總已納管且允許瀏覽的範圍，不擴大掃描、不初始化記錄、不穿過遊戲／App 保護邊界。範圍與檔案類型過濾彼此獨立，未完整列舉須明示已納入範圍與載入／失敗狀態。
- 「依來源分組」為展示選項，可與瀑布流／縮圖／列表搭配，不新增第四種排列方式；主要用於包含子資料夾時，各來源區塊可收合。每檔保留來源識別，分組標頭提供資料夾名稱、相對路徑及前往來源圖示；長路徑單行省略，完整內容可透過 Hover／鍵盤聚焦查看。同名檔案以來源身分＋檔案身分區別，不以檔名或單一檔案 ID 合併。

### 右側組件共用邊界

- 現行右側外框已由 BrowseWorkspace 共用標題／導覽、設定、顯隱、尺寸與返回頂部；不再建立另一份外框或重複導覽狀態。內容仍由 FolderContent 分流，媒體頁使用 MediaBrowser，漫畫圖庫共用 Gallery，遊戲保留專用內容。

- 三種內容的讀取仍沿用受控 API 與來源身分，按實際相同行為共用分頁、過期回應防護與展示過濾，不強行套用同一查詢範圍。載入／切換／失敗不能額外建檔、重設草稿或啟動媒體；抽取後才清理確認無呼叫的重複碼，不刪除單檔預覽相容路徑。
- 驗收以漫畫／媒體／遊戲的同等路徑、子資料夾、空白／錯誤、缺失／保護記錄及三主題／窄窗為基線，再查專用閱讀／啟動／背景播放生命週期；來源與保存安全規則不因共用 UI 簡化而省略。

### 大視窗與媒體清單

- 大視窗覆蓋整個應用程式可視區，不自動切換作業系統全螢幕，也不建立另一個原生視窗；保留獨立、明確操作的全螢幕／漫畫沉浸能力。關閉／ESC 沿既有分層規則，還原來源位置、選取與捲動。所有媒體佇列每次開啟檢視器預設關閉，以圖示呼出，寬／窄視窗一致；不新增未核定的記住展開狀態設定。
- 佇列以右側覆蓋層滑入／滑出，不擠壓主內容；開啟與關閉皆有平順過渡，快速切換以最後狀態為準，遵循減少動態效果偏好。過渡不重新掛載播放器、不換來源、不重設頁碼／縮放／播放位置，避免主內容尺寸重算造成抖動；收起後清單不可聚焦或誤點，焦點回開關。首次展開才掛載清單，當次收合保留展示方式與清單狀態；只隱藏佇列不停止播放或改變清單。
- 圖片／文件開啟時，以所選檔案的實際來源資料夾及當次篩選、搜尋、排序建立同類清單；瀏覽根與檢視來源可以不同，但此類清單只有一個來源。「展示的媒體」指符合條件的完整結果，包含分頁／虛擬化尚未掛載的項目，並非只有螢幕上可見縮圖。排除其他來源、其他類型與已隱藏檔案；未載完時明示筆數／載入狀態，不捏造總數。
- 圖片／文件清單固定來源與條件，分批補齊仍按同一排序；背景列表篩選不暗中換項目。影音改採下述跨專案播放佇列，與目前資料夾檔案清單分開，不再限制單一來源；來源失效需標示原因，不因錯誤自動播放下一個。首版不跨重啟保存佇列或播放位置。
- 圖片沿用縮放／資訊，漫畫保留 RTL、單雙頁、首張獨立、頁序及原子換頁；一組雙頁仍以檔案身分定位，不增加重複佇列項目。一般圖片不自動變漫畫，明確選擇閱讀模式並保留已有偏好。PDF／ZIP／CBZ 的外側清單是同資料夾同類文件，文件內頁碼獨立，不串接多份文件或不同作品。
- 影片保留時間軸、音量、倍速、字幕與明確接續開關；影片佇列新增 [縮圖展示](VIDEO_VIEWER_DESIGN.md#影片佇列展示)。音樂保留基本播放控制、專輯封面與播放順序。共用外框、選取、清單與關閉生命週期，不強行共用媒體控制列。PDF／ZIP／CBZ 等已有內建檢視能力的文件仍可使用對應佇列。
- 目前不支援檢視的檔案不得進入大畫面，也不加入可切換觀看的佇列；仍在檔案清單顯示名稱、類型與不支援原因，保留適用的資訊及開啟所在資料夾入口，不讓檔案消失。所有開啟入口均適用此限制。副檔名／類型分類不等於已能解碼；原本支援但損壞、失效或解碼失敗者明示實際錯誤。外部開啟仍須明確操作與授權，EXE／腳本不自動執行。

### 播放、效能與相容

- 新媒體頁進資料夾只顯示檔案，不因混有影片／音樂就啟動新的播放器；明確開啟影音才播放，不打斷既有全域播放。舊影片專案的進入自動播放偏好轉換仍須明示，不默默刪除設定；接入共用播放前須處理其與現有播放的衝突。不記錄影片觀看位置；混合影音佇列提供自動接續開關，預設關閉，最後一項停止，失敗不自動跳過，上一個／下一個仍可手動切換。
- 已啟動的影音可在切資料夾／專案及離開大視窗後持續播放，由應用程式內迷你播放器控制；隱藏右側瀏覽區不停止全域播放。共用同一播放工作階段，避免大視窗、迷你播放器與舊入口同時發聲；縮放呈現不重新讀來源或重設進度。停止／移除來源時仍解除來源、取消待播／讀取並忽略過期回應。應用最小化可續播，關閉應用即停止，不跨重啟恢復播放。

### 跨專案影音佇列與迷你播放器

- 大視窗右側分為「播放佇列｜目前資料夾 XX」兩個 TAB，後者標示資料夾名稱、列出該資料夾的音樂／影片並提供加入操作；可從不同專案／資料夾將音樂與影片加入同一播放佇列。加入只追加到尾端，不打斷目前播放；資料夾瀏覽／篩選不覆寫既有佇列，也不自動加入全部檔案。允許重複加入，每次建立獨立佇列項目，排序／移除不影響其他同檔項目。
- 檔案列表／卡片與「目前資料夾 XX」TAB 採一致操作：移除各項目常駐的「＋」按鈕，單擊音樂／影片只立即播放，不自動追加或清空既有佇列；右鍵選單提供「加入播放佇列」。多選後加入依目前列表順序追加選取項目，不改成選取點擊順序；保留重複加入、來源驗證及不打斷目前播放的規則。右鍵選單需可由鍵盤開啟及操作，不自行新增未核定的全域快捷鍵。首批實作右鍵與多選加入（Ctrl／Shift 點擊或 Shift＋方向鍵多選）；拖入佇列列為後續擴充，不作首批阻礙。單擊的未入列單曲為獨立試播（2026-10-31 核定）：不改既有佇列，上一個／下一個與播畢自動接續不動作，也不默默接到佇列首項；若同一來源檔案已在佇列，單擊定位該項並沿用其順位。
- 播放佇列與目前資料夾 TAB 需重新設計視覺層級，沿用既有三主題、圖示與控制尺寸；兩份列表採一致列高、間距與文字對齊，避免目前整列置中、粗體強調色按鈕的呈現。檔名為主要內容，長名稱單行省略並可查看完整名稱，必要時以次要來源資訊區分同名項目；播放中與僅選取狀態可辨，強調色不套用於所有檔名。佇列入口位於頂部工具列（清單圖示加數量，佇列非空才顯示），不再使用右下角浮動按鈕以免遮擋返回頂部；播放佇列提供清單／圖片兩種呈現，內容與順序不變（2026-10-31 核定）。拖排／移除操作與自動接續設定各有明確位置，後者屬播放佇列設定，不作目前資料夾列表的內容。鍵盤焦點標示仍需清楚，不為外觀移除可存取性；保留雙 TAB 的職責與既有播放、排序、來源及安全規則。
- 每個佇列項目保留原始專案、資料夾及檔案身分；跨專案不代表可繞過來源授權、遊戲邊界、缺失記錄或檔案存取限制。專案移除／來源失效需停止受影響項目並明示，不因播放初始化或重建來源記錄。
- 背景播放時，應用程式內預設右下角顯示迷你播放器：影片顯示畫面，音樂顯示封面／佔位；提供播放／暫停、可拖曳進度條、上一個／下一個媒體及返回大視窗佇列入口，沿用主題樣式。
- 迷你播放器可從非控制區拖曳，放下時依距離貼齊應用程式可視區最近的邊緣；保持在可視區內，視窗縮放時重新約束位置。控制元件操作不觸發拖曳；貼邊過渡遵循減少動態效果偏好。不據此建立桌面置頂原生視窗或作業系統 PiP。
- 迷你播放器移到頂端後，拖曳仍只移動播放器，不得觸發 Electron 原生視窗拖移。需檢查自訂 Topbar 的 drag region／命中範圍、播放器與控制的 no-drag 區域及指標捕捉；實際成因待重現，不先斷定只需調整 z-index。頂端貼邊保留應用 Topbar 的原生操作區，控制元件與拖曳手把不落入原生視窗拖曳命中區。驗收頂部／角落、最大化／還原、縮放與快速拖放，應用視窗位置保持不變。
- 佇列支援拖排及逐項移除；移除正在播放的項目即停止，不自動換播。大視窗提供「縮小播放」進入迷你播放器，迷你播放器關閉即停止並解除來源；返回大視窗則保留播放狀態。首版不跨重啟保存佇列或播放位置；迷你播放器採最近邊緣貼齊，保留沿邊位置與小間距，不加調整大小功能。此批實作與查收狀態見 [工作清單](WORK_ITEMS.md)，重複加入已核定。
- 沿用分批列舉、虛擬化、可見縮圖、受限快取與相鄰預載；GIF 只在可見範圍播放，開大視窗停止背景動畫。驗收大量混合媒體、快速切換、損壞／消失／權限失敗、窄視窗、主題、鍵盤焦點與原檔不變，不以統一 UI 代替既有解碼與安全驗證。
- 屬性只決定呈現能力，不更換 folderId、來源身分、共用值或私有覆寫；保留 CELL 方案、封面、來源匯入及讀取偏好，來源清單依資料種類選擇，不因四種屬性合併而失去音樂／圖片等來源。先確認新屬性在建立、驗證、保存重開、匯出入及舊版本的接受行為，再實作最小相容轉換；不能只加 UI 選項或逕改既有分類值。
- 退役前須有受控轉換預覽、備份／失敗復原與舊資料回開驗證，明列跨層瀏覽等差異；新頁查收不等於授權清理真實收藏。只移除已無呼叫的舊入口／重複程式，保留共用解碼器與原媒體。已交付階段與後續差距見 [待辦](WORK_ITEMS.md#統一媒體工作區執行順序)。

### 音樂播放故障與選型

使用者回報 MP3 在新舊專案均不能播放：檔案與封面可顯示，但時長為 `0:00`，點擊播放無反應。已取得指定樣本並以副本重現開發模式的 StrictMode 音源清理問題；修正及實際驗證狀態見 [工作清單](WORK_ITEMS.md#最新回饋)。播放器沿用既有 Video.js，舊音樂入口保留原屬性及內容版面。封面讀取與音訊播放是不同路徑，不以封面或受控解碼成功代替使用者環境／硬體輸出驗收。

- 先取得失敗格式與操作，區分來源授權、MIME／Range、解碼錯誤、play Promise、音量／靜音及視窗可見性／生命週期；不以介面出現就判定成功播放。
- 音樂音量的使用者介面以 0～100 表示，含滑桿數值提示與可存取數值，不顯示內部 0～1；內部播放 API 與既有保存值維持原契約，不為顯示換算修改資料格式。
- 音樂進度條與音量條的未填滿軌道需有清楚、低對比的底色，讓使用者辨認整條可操作範圍及總長度；已填滿段、滑塊與背景須可區分。沿用主題 token，涵蓋淺／深色及玻璃主題；0%、中段及 100% 均維持可辨識，不靠 Hover 才顯示底軌。不以模糊封面背景取代軌道對比；不改播放、拖曳與鍵盤操作。
- 音樂大視窗側欄與背景播放依 [跨專案影音佇列](#跨專案影音佇列與迷你播放器)，與 MP3 故障修正分批驗收；顯示佇列或封面不能當作播放通過。
- 先前受控 WAV 為靜音素材，只驗證時間前進及停止／卸載，不代表實際音樂可發聲或其他格式已支援。後續用可聽的受控音訊與失敗格式的安全樣本驗證，原檔保持不變。
- 封面來源與播放佇列分開，不能因檔案列表篩選為「音樂」而被排除。優先序為使用者明確指定封面 → 音訊內嵌封面 → 同資料夾 cover／folder／front／album 圖片候選 → 中性佔位。未指定時只有一個命名候選才自動展示，多個候選由使用者選擇，不任選第一張圖片。播放器可從目前來源的可見圖片選擇當次封面，不寫入原音訊或可攜記錄；跨次指定仍沿用資料夾封面設定。未指定、載入中與失敗分別提示；能播放不代表封面已通過。
- 內嵌封面由 main 的受控 `audio-cover` 媒體端點讀取，重用檔案身分、路徑／記錄與保護邊界驗證；採 music-metadata 及唯讀 Blob 隨機存取，不整份讀入記憶體或計算完整曲長。解析工作串行執行，已取消的排隊請求不開始讀取。此入口限 256 MiB 音訊／8 MiB 封面，超限或不支援時明示讀取失敗並允許外部圖片備援，不影響音訊串流；圖片依實際簽名驗證，不直接信任 metadata MIME。Blob URL 隨切換／關閉撤銷，忽略過期結果；未新增可攜格式。
- 比較現有 Video.js、原生 Audio 基準及外部候選的重現結果、維護、文件、自訂能力、Electron 適配與依賴成本，再選最小修正或替換；授權／串流／解碼問題須先處理對應層，不推定換介面套件就能解決。

## 工作區介面細節

以下為 2026-10-29 核定目標，實作差距見 [當前工作](WORK_ITEMS.md)；細部尺寸及動畫數值為可調基線。

- 檔案模式的資料夾選擇需適合長路徑與大量資料夾。以資料夾名稱為主、單行省略的相對路徑輔助辨識，完整路徑可在 Hover／鍵盤聚焦時查看；支援名稱／路徑搜尋、鍵盤選取，選單高度受可視區限制並可捲動，不讓任意長路徑換行擠掉其他選項。同名資料夾保留來源區分，選取仍沿用既有授權與範圍。
- 屬性為遊戲時隱藏「檔案」檢視模式，維持資料夾瀏覽與遊戲專用內容。切換專案／分類或載入舊偏好時，若留有檔案模式需回退資料夾模式；不以隱藏入口取代遊戲 ROOT 的既有保護。
- 左側專案欄與右側內容欄的開啟／隱藏加入平順過渡，避免內容突跳；中途反覆切換、調寬及窄視窗不得造成殘留空間或焦點落在隱藏內容。遵循減少動態效果偏好；隱藏當下仍按既有規則停播／取消讀取，不延後到動畫結束。
- 資料夾候選一次最多顯示 100 筆，名稱／完整路徑搜尋仍涵蓋所有允許選取的資料夾；同名項目以相對路徑區分，鍵盤移動時提示完整路徑，無符合項目時顯示提示。側欄過渡只保留寬度容器，右側內容隱藏即卸載，隱藏區立即禁止焦點與操作；拖曳調寬不套開合過渡。
- 資料夾／檔案切換時，共用工具列組件的寬度與對齊保持穩定，不因切換內容而跳動；窄視窗仍依一致的響應式分組換行。
- 檔案模式的資料夾候選先按相對 ROOT 的深度升序（ROOT 為第 1 層），同深度按資料夾名稱的固定字元編碼序排序；同名以相對路徑穩定排序。搜尋篩選不改排序，截取可見候選前先排序，不採自然數字／語系排序。
- 專案 ICON 按遊戲、音樂、漫畫、圖片／相簿、影片等屬性區別，未知類型有通用回退；新增圖示沿用共用 SVG 風格。群組拖放完成後，項目移位有平順過渡，尊重減少動態效果偏好，保留排序保存與鍵盤操作。

## 設定包移轉

「應用程式設定 → 設定移轉」匯出 schemaVersion 1 的 media-viewer.settings JSON，僅允許群組、收藏／專案排序、側欄、主題、語言、音量及瀏覽操作偏好；不含媒體、registry 路徑、單機 browse 位置或未知／登入欄位。匯入先預覽差異，預設合併保留目前同身分設定，可明確改為取代；媒體連結保持原樣。預覽 token 綁定目前 revision，過期需重看。

每次套用／復原先把目前 workspace 設定原子備份到 userData/workspace-backups，再保存；備份或保存失敗不切換記憶體狀態。備份清單可復原，復原前也備份目前狀態。匯出檔案已存在時只覆寫可辨識的設定包，保留獨立 UUID 備份，拒絕覆寫其他 JSON 或可攜媒體目錄。匯入不掃描／遷移實際收藏，schemaVersion 仍為 1；雲端同步延後。入口 electron/settings-package.ts、electron/settings-file.ts、electron/workspace.ts、ApplicationSettings；驗證 tests/decided.test.ts、tests/decided-media.test.ts、tests/decided-ui.ts。
