# 圖片／相簿內容與圖片檢視窗

此頁持有相簿／圖片檢視的核定目標；共用焦點／媒體生命週期見 [UI_RULES](UI_RULES.md)，中央跨層檔案總覽見 [工作區](WORKSPACE_REVISION.md#檔案總覽)。實作差距／待查收只留 [當前工作](WORK_ITEMS.md)，不能以規格或舊驗證推定已交付；程式入口與測試見 [索引](README.md#按任務定位)。

來源為 C-81、C-83、C-85 與後續圖片閱讀器要求；雙模式、基本資訊及共用底層仍有效，格式不以早期四格式為上限。線稿不指定最終風格。

## 圖片內容

舊相簿分類定義與適用單檔預覽保留相容，資料夾內容已共用媒體頁；目前呈現採 [統一媒體工作區](WORKSPACE_REVISION.md#統一媒體工作區) 的右側檔案展示與圖片單來源清單，不將此限制套用到跨專案影音佇列。下列圖片比例、縮放、資訊與效能規則繼續共用。

此畫面位於選定資料夾的內容區，承接 CARD／TREE／TABLE 的資料夾選取；以下兩種是資料夾內圖片的呈現方式，不是新增專案瀏覽模式。

| 區塊 | 已確認行為 |
| --- | --- |
| 瀑布流 | 圖片高度不固定，依圖片比例排列，參考圖 1。 |
| 列表 | 提供圖 2 的檔案列表模式；名稱、修改日期、大小為線稿參考欄，欄位操作仍待細化。 |
| 圖片檢視窗 | 點圖片開啟較大的觀看視窗，可放大查看細節，顯示長、寬、圖片類型等基本資訊，ESC 退出。 |

## 已採互動與實作基線（C-83）

- 瀑布流採同欄寬、依原比例顯示完整縮圖，不為填滿格子裁掉內容；調整內容區寬度時重新分欄。維持一份穩定檔案排序，切列表或進檢視窗不換一套順序。
- 列表預設縮圖＋名稱／修改日期／大小；C-85 採點列先選取、點縮圖開檢視窗，排序／調寬依局部規格，不直接複製 C：TABLE 的專案欄位設定。
- 檢視窗提供寬／高適應、放大／縮小、拖曳平移、縮放百分比、重設及資訊顯隱，縮放規則由 [圖片閱讀器](#圖片閱讀器) 持有。相鄰圖片切換可共用漫畫的圖片清單及預載能力，不直接加入漫畫雙頁規則。
- 基本資訊建議為檔名、像素寬高、格式、檔案大小、修改時間；副檔名與實際解碼格式需區分，未取得資料顯示未知，不編造數值。EXIF 方向需正確呈現，是否額外展示拍攝時間／相機／位置留後續。
- 關閉後保留原資料夾、圖片選取與捲動位置。ESC 先關最上層選單／檢視窗，再處理原工作區放大，避免一次退出兩層。
- 圖片檢視統一單擊圖片即開啟閱讀器，移除圖片預覽中額外的「開啟檢視器」按鈕；適用縮圖及檔案模式的圖片預覽。此要求只限圖片，不由此推定移除 ZIP／PDF 的文件檢視入口。

### 圖片檢視形式已選程式內覆蓋層

| 方案 | 適用與取捨 |
| --- | --- |
| **程式內獨立檢視覆蓋層（C-83 已選）** | 可共用漫畫縮放、載入與退出能力，實作及狀態同步較少；不能拖出主程式到另一螢幕。 |
| 原生獨立 Electron 視窗（保留未來） | 可跨螢幕、與主畫面並排；需額外處理視窗生命週期、受控讀檔及同步。 |

## 圖片閱讀器

以下為 2026-10-29 核定目標。使用者回報的縮放抖動、原尺寸按鈕移除及完成狀態由工作清單追蹤，不能把本節當作已修正證據。

- 修正連續滾輪及按鈕縮放時的抖動，維持縮放錨點與平移穩定；實作時檢查尺寸量測、捲軸與適應基準互動，不預先將某個原因視為已確認。
- 寬度適應時圖片左右貼合可視內容區邊界，高度適應時上下貼合；可視內容區扣除工具列與資訊列，不保留額外內距。保持圖片比例，另一方向可有留白；視窗大小或資訊列顯隱變化後重新貼合。
- 移除「100%／原尺寸」按鈕，保留「重設縮放」：回到目前選用的寬度／高度適應基準並重設平移，仍可繼續放大查看細節。縮放百分比讀值保留，不再提供獨立原尺寸按鈕。
- 本項適用圖片／相簿閱讀器；共用 Reader 修改需驗證漫畫既有縮放與平移，不恢復漫畫已移除的寬度／高度適應控制。既有閱讀偏好需相容處理，不批次改寫使用者圖片或可攜記錄。
- 縮放／重設快捷鍵、方向按鈕及整個頁碼框的點擊契約見 [共用閱讀器操作](UI_RULES.md#共用閱讀器操作)。
- 適應基準使用不受捲軸影響的完整可視尺寸，圖片區不另加內距；放大後沿用拖曳平移。連續事件在同次更新保留同一縮放錨點。百分比以目前適應基準為 100%；舊 `original` 偏好載入時回退高度適應，只沿用既有退出保存流程，不批次遷移記錄。

## 檔案與效能基線

- 資料夾右側內容列目前資料夾直接圖片；中央跨層檔案總覽是獨立觀看範圍，不把專案掃描深度直接套成圖片遞迴。格式先以可解碼的 PNG／JPEG／WebP／GIF 作驗收起點，HEIC／RAW／TIFF 等不宣稱已支援，需確認必要性與解碼成本。
- 共用漫畫的檔案列舉、縮圖快取、圖片解碼及檢視能力，保留不同版面與用途。原始圖片唯讀，直接讀現有圖片不全部再複製到 `.media-viewer/assets/`；使用者匯入的自訂資產沿用可攜保存規則。
- 相簿／漫畫內容先回傳前 96 筆，後續每批 256 筆背景讀取，顯示已載入圖片數及讀取中狀態；切換資料夾即停止接續舊批次。主程序保留有限、短期的唯讀檔名快照與游標，每批仍驗證資料夾身分及檔案路徑，不從快取補建記錄。影片與其他既有單次內容 API 保持相容。
- 保留每組最多 200 張與自然檔名順序；瀑布流、列表和漫畫網格只建立可見範圍及前後少量預載項目，離開後卸載圖片並保留尺寸模型。瀑布流的欄位歸屬固定，避免圖片解碼後跨欄重排；實際比例批次更新，調整高度時保留捲動錨點，使用者的新捲動優先。列表縮圖固定 45px／列高 60px；漫畫縮圖網格列高固定，無須逐張比例重排。尺寸均為可調基線。鍵盤方向鍵／Home／End 可移動並捲至未掛載項目；分組切換回到頂部，切換瀏覽模式保留近端項目。
- 圖片縮圖經受控原圖串流非同步解碼並在解碼時縮小，不在 main 同步解碼完整原圖，也不傳送原圖 Base64。縮圖命中直接讀本機快取，不排在冷解碼後；相同工作合併、已取消的排隊工作跳過，版本 URL 可快取。快取清理同時只執行一次且限制頻率；只清理既有受管縮圖，不寫原始媒體。閱讀器按需載入，點開才處理細節原圖。
- 依 C-83 採推薦，共用漫畫的 GIF 可見播放、視窗外停止能力，檢視窗開啟時停止背景動畫，不增設固定播放張數上限；相簿實際效能仍須另外驗證。
- 預設不顯示本程式自身記錄與快取；損壞、無權限或無法解碼的圖片需有佔位與原因。瀏覽／縮放不自動建立逐圖標籤、逐圖可攜記錄或修改 EXIF。

## 驗收與未決事項

後續以受控圖片資料夾驗證直幅／橫幅／長圖、視窗調寬、模式切換保留定位、放大平移、尺寸及格式資訊、損壞／缺失、ESC 與原始檔不變；大量圖片另檢查載入及記憶體，不以縮圖存在宣稱已完成大量資料驗收。

HEIC／RAW／TIFF 等擴充依 [後續範圍](OPEN_DECISIONS.md) 排程；中央跨層檔案總覽的既有能力見工作區，不再把它列為圖片頁未決事項。瀏覽尺寸／捲動先存本機，每筆閱讀偏好與版型保存依 C-85，未定的排序／格式細節保留待細化。歷史受控證據可追溯 [0.5.0](RELEASE_0_5_0.md) 及 [0.7.0](../CHANGELOG.md#070--2026-10-29)，不代表本次重新驗證。

## 單檔預覽標題

圖片預覽的「開啟所在資料夾」以低強調圖示放在檔名旁，長檔名截斷並提供完整標題；只開啟目前圖片來源資料夾，圖片仍單擊進閱讀器。
