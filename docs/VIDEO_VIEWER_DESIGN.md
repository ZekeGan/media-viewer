## 播放控制

使用者要求 YouTube 式控制列，並確認「放大／縮小」只指進入／退出全螢幕；不加入畫面放大平移或劇院模式。沿用已安裝的 Video.js 媒體元件，控制列改由 `VideoControls` 組合，使用同一個 HTMLVideoElement，無新增依賴。

- 上排為可拖曳進度、緩衝範圍與滑過時間；下排為播放／暫停、上一部／下一部（有播放清單時）、音量／靜音、時間、更多播放設定與全螢幕。移除快退／快進 10 秒按鈕，快捷鍵保留；窄區域固定分行，避免音量展開時改變喇叭位置而反覆收合。
- 播放時閒置約 2.5 秒隱藏控制列；滑鼠移動、鍵盤聚焦、暫停、設定開啟、音量拖曳、錯誤或接續倒數時顯示。控制列外層及空白處透明，只有實際按鈕／控制群組使用半透明圓角底；不以整條灰底或全畫面漸層遮蓋影片。音量平常只顯示喇叭，hover／鍵盤聚焦展開滑桿，移動到滑桿或拖曳期間保持展開；點擊喇叭仍切換靜音。進度強調色沿用全域主題；操作圖示／名稱沿用共用圖示及五語言。
- 全螢幕由播放器容器使用 Fullscreen API，保留同一播放實例與控制列；按鈕／F／雙擊影片切換，Esc 退出。更多面板及字幕選單／顏色選擇器留在該容器內，面板限制寬高、內容可捲動，避免跑出窄播放器或全螢幕範圍。面板內 Esc／關閉按鈕收起並將焦點回到齒輪；字幕位置預留可見控制列的高度。離開時釋放自身全螢幕，不影響其他容器。
- 快捷鍵只處理播放器內焦點：K／Space 播放暫停，J／L ±10 秒，左右鍵 ±5 秒，上下鍵音量 ±5%，M 靜音、C 字幕、F 全螢幕；輸入框、選單與設定面板保留自身鍵盤操作。播放速度提供 0.5／0.75／1／1.25／1.5／2 倍，本次瀏覽切片時保留。
- 倍速、自動播放及字幕入口集中 [播放設定](#播放設定)；控制列不另放 CC 按鈕，字幕快捷鍵保留。播放與字幕狀態依下列生命週期處理。

可攜 schemaVersion 維持 1，`videoAutoNext` 為可選布林值；初次建立與舊專案皆不需遷移。驗證定位見 [IMPLEMENTATION](IMPLEMENTATION.md#測試定位與失敗處理)。

## 播放設定

常用選項為進入資料夾時自動播放、播完接下一部與倍速；低頻字幕設定收在父群組。調整即時預覽，明確保存才寫回逐片／來源設定，保存失敗保留草稿及原因。

- 一般開啟播放設定時，常用播放選項優先顯示；「字幕來源／同步與編碼／字幕外觀」統一收納在可開合的「字幕設定」群組，預設收合。展開後才顯示三個子區塊，詳細控制按需展開；收合不清除已載入字幕或未保存調整。只開啟一般設定不再因缺少字幕而自動展開來源；明確使用字幕快捷鍵或多檔字幕拖入時，仍可直接展開來源完成操作。
- 面板依播放器自身的控制列、觀看對比與可用空間重設，不能只套用全域表單配色。可調設計基線為配合播放器的深色半透明面板、高對比文字／圖示、精簡選項列與清楚群組層級；選項名稱、目前值及開關位置一致。主題強調色、共用圖示及語言沿用應用設定，實際密度與透明度依播放器截圖查收調整。
- 群組展開時面板仍限制在播放器內，適應窄視窗與全螢幕；捲動、關閉、Esc／焦點返回、字幕預覽與明確保存沿用現行契約。不恢復獨立字幕 Modal、重複上方設定入口或全畫面黑影。

## 字幕入口

字幕顯隱、載入與設定集中在播放設定內的字幕群組；群組內提供字幕顯隱開關，未載入字幕時停用，來源子群組負責載入／移除。控制列不另放 CC 按鈕；保留字幕拖入、C 快捷鍵與逐片／來源保存，未有字幕時按 C 可直接開啟來源群組。

## 播放生命週期

以下進入資料夾自動播放及右側上下配置適用既有影片分類；新媒體頁的入口、清單與停止條件由 [統一媒體工作區](WORKSPACE_REVISION.md#統一媒體工作區) 持有。新核定的 [跨專案影音佇列與迷你播放器](WORKSPACE_REVISION.md#跨專案影音佇列與迷你播放器) 尚未實作，其背景播放目標取代共用影音切資料夾即停播限制；以下舊入口規則不可套用為新佇列限制。解碼、字幕、音量及過期來源防護繼續沿用，舊偏好接入共用播放的衝突仍需處理。

- 同時只啟用一個播放實例，下方影片使用縮圖。進入資料夾預設從頭播放第一支，`project.videoAutoplay` 缺省為開啟；關閉時不自動播放，但明確點選縮圖仍播放。不記錄／恢復觀看進度，舊時間欄位僅相容保留。
- 音量及靜音由本機 `workspace-ui.json` 的可選 `videoAudio` 保存，不寫入媒體或可攜記錄。初次取得偏好前維持靜音，待設定就緒才啟動要求的播放；只有使用者修改才排程保存，失敗可繼續播放並顯示未保存原因。
- 「進入資料夾自動播放」沿用 `project.videoAutoplay`，與新增 `project.videoAutoNext` 獨立。`videoAutoNext` 缺省／false 不接續；只有明確啟用後，片尾才顯示下一部檔名、5 秒倒數、取消與立即播放。只依目前資料夾直接影片的既有排序，不跨子資料夾，不循環，不因解碼失敗自動跳過。最後一部停止。
- 切片、定位進度、關閉接續設定、開啟更多設定、離開內容或隱藏應用都取消待播倒數。離開資料夾／專案仍停止並解除舊影片來源；隱藏／最小化時暫停，重新顯示不恢復已暫停的播放。除 DOM 可見性外，也監聽原生 `window:state.visible`，避免 Windows 視窗隱藏時頁面未收到隱藏狀態而繼續播放。既有「不記錄觀看進度、不自動續播」維持。
- 關閉內容／切換資料夾或專案時，從實際媒體節點卸載回呼暫停、移除 src 並取消載入；metadata 及 play Promise 僅允許目前仍掛載節點啟動，不以 autoPlay 與載入事件雙重啟動。
- 切片移除上一支字幕與拖入清單、重設展開狀態，過期載入結果不套用新片；載入／解析失敗保留原字幕。捲動出畫面的影片行為仍需按情境細化，不直接套用 GIF 排程。

## 格式限制與本機傳輸

**介面套件不等於解碼引擎。** 採用 Video.js 或 ArtPlayer 不保證任意 MP4、MKV、AVI、HEVC、音軌或字幕都能播放；容器與內部編碼不同，實際能力取決於播放器使用的媒體後端及目前 Electron／Windows。需以影音皆可解碼、可拖曳定位作驗收，不能只看副檔名。[媒體容器與編碼說明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats/Containers)

- 先以實際可播放的 MP4（H.264／AAC）及 WebM（VP8／VP9／Opus／Vorbis）樣本建立支援矩陣；這是已採方案的驗收起點，不是現在已驗證支援。HEVC／MKV、多音軌、完整 ASS 等擴充分期見下節。
- 若需要廣泛本機影片相容性，應另外比較原生解碼／外部播放器的部署、授權與控制成本，不以更換 HTML5 控制列當作解決方式。首輪不預設加入 FFmpeg 轉碼、不改原片。
- 可攜資產沿用 `media://asset`；原始媒體透過 `media://file/<rowId>/<fileId>` 與 `Explorer.stream` 讀取，主程序提供 Range／206／416 與取消路徑。存取仍須驗證有效資料夾及實際路徑，不能因已有串流程式就宣稱任意大檔／格式皆經驗證。
- 媒體 URL 使用受控資料夾／檔案識別，遵守 main／preload 邊界；驗證目前實體路徑、junction／越界、MIME、取消及缺失。不開放 renderer 任意絕對路徑讀取。
- 大檔須串流，支援並驗證 Range／206、Content-Range 及錯誤範圍等行為；避免整片轉 Base64 經 IPC。Electron 自訂串流協定需核對 `stream` 特權與請求轉送，不能把現有圖片讀取流程直接當作完成。[Electron protocol 文件](https://www.electronjs.org/docs/latest/api/protocol)
- 縮圖與可重建資訊放本機快取，按需取得，不為列清單讀完整影片或複製原片到可攜資產區。觀看進度不恢復；字幕來源／偏好由下節持有，快取上限是可調工程基線。

## 已採格式分期與保留分析（C-85）

本專案是本機媒體瀏覽器，字幕與常見收藏格式有價值；C-85 已採下列分期，不將所有容器／編碼／字幕列成首輪必達。分析與相容性目標不是現有能力聲明。

| 類型 | 是否值得支援／推薦範圍 | 原因及限制 |
| --- | --- | --- |
| 外掛 SRT／WebVTT | **字幕功能首輪推薦必做**：拖入、切換／關閉、時間調整與基本外觀。 | 先完成可用的字幕閉環；Video.js 內建路徑以 WebVTT 為主，SRT 需解析／轉為播放用 cue，不改原檔。 |
| 外掛 ASS／SSA | 值得納入後續相容性階段；若主要用途為依賴 ASS 的動畫收藏，應提前。 | 有排版、字型及特效，轉成純 VTT 會損失表現，不能稱完整支援。評估 JASSUB／libass 等專用渲染器，非只改副檔名。 |
| MKV | 列入相容性目標，但不當首輪全支援門檻。 | 它是容器，能否播放還涉及其中視訊／音訊編碼、軌道與解封裝；能列出檔案不等於能完整播放。 |
| HEVC／H.265 | 列入相容性目標，先用 Windows Electron 樣本驗證，再決定補後端。 | 它是視訊編碼，與 MKV 不同層次；部署版本、解碼及硬體差異不能靠 UI 套件解決。 |
| 內嵌字幕／圖形字幕／多音軌 | 另訂階段及樣本。 | 拖入外掛字幕不等於已會抽取容器內字幕；沒有解析能力時標示未支援，不顯示成「沒有字幕」。 |

兩種策略：**A（C-85 已採）**沿用已選 Video.js，首輪 SRT／VTT，ASS 及 MKV／HEVC 逐步驗證擴充；**B（實際需求出現再評估）**採 mpv／libmpv，以廣泛本機影音為優先，但需額外處理原生部署、畫面嵌入、控制及授權。若 B 成為必要另開後端選型，不假設可直接塞進 Video.js。[mpv 官方手冊](https://mpv.io/manual/stable/)

本輪查閱的重要限制：Video.js 目前官方說明只有 WebVTT、沒有現成的觀眾字幕樣式設定選單，因此 SRT 載入／同步及簡化設定面板是本專案要補的能力，不能宣稱裝套件即完成。[Video.js 字幕](https://videojs.org/docs/framework/react/guides/captions)、[目前字幕缺口](https://videojs.org/docs/framework/react/guides/migrate-from-vidstack)

JASSUB 可作 ASS 研究候選；其 WASM、Worker、字型及本機資源載入也需驗證，不在本輪鎖定或安裝。保留 ASS 原版面需用對應渲染能力，不以純 VTT 近似後隱藏功能損失。[JASSUB 原始專案](https://github.com/ThaUnknown/jassub)

## 拖入字幕與同步設定

**C-84、C-85 已採互動**：字幕拖至上方播放器即可載入。首輪 SRT／VTT 與以下操作／設定作設計基線，格式與實體契約需驗證：

1. 下方字幕項目可拖到播放器，顯示將套用的影片名稱；有目前影片且格式支援時立即切換到該字幕，不重播或更換影片。不支援／解析失敗顯示原因並保留原字幕；未選影片時先引導選片。
2. 同時拖多份時提供字幕來源選擇，首輪一次顯示一條，可切換／關閉；不默認合併成雙語字幕。檔案總管拖入可共用入口，由 preload／main 驗證實際選取檔案，不開放任意字串路徑。[Electron 拖入檔案路徑介面](https://www.electronjs.org/docs/latest/api/web-utils)
3. 原資料夾內字幕用相對引用，不重複複製；外部拖入先作本次播放來源。若要跨設備保存外部字幕，另提供明確匯入可攜副本的選項，以資料夾內的相對引用保存，不把舊絕對路徑當可攜保證。
4. 文字以 UTF-8 為起點；亂碼需能重選文字編碼，具體編碼清單待樣本確認。不因讀取失敗覆寫原字幕。自動同名匹配先不代替使用者的拖入選擇。

| 問題 | 推薦設定／處理 | 不作的保證 |
| --- | --- | --- |
| 整段字幕固定太早／太晚 | 「提早／延後 0.1 秒」、直接輸入秒數、重設；明示正值＝晚出現，例如 +0.5 秒讓原 10 秒字幕在 10.5 秒出現。 | 不靠模糊正負號讓使用者猜方向。 |
| 開頭同步、越播越不同步 | 提示可能為不同剪輯／時間軸或幀率版本，優先換正確字幕；兩點校正／比例調整列後續。 | 固定延遲不能修復所有逐漸累積的時間差，也不自動改影片速度。 |
| 字太小、看不清或太靠下 | 簡化字幕設定：字體／大小、文字與背景或描邊、底部距離、重設；底部位置以實際影片畫面比例計算。 | 不保證套件內建已有這些設定或所有 cue 樣式都可任意控制，需實測。 |
| 縮放／全螢幕後位置跑掉 | 字幕依實際影片顯示區與同一時間來源定位，重算畫面尺寸，保留留白與控制列安全空間。 | 不以外層卡片的固定像素位置當影片座標，也不把 ASS 作者排版全覆蓋成一般字幕樣式。 |
| 拖曳進度／倍速／暫停後錯位 | 使用媒體播放時間作字幕時鐘，seek／切片／重播同步更新，不另用牆鐘計時；字幕來源切換釋放舊軌。 | 不用每次載入累加延遲，避免重複字幕與二次校正。 |

簡化設定建議由本專案小型面板補足，沿用現有 UI 能力，不另做完整字幕編輯器。WebVTT 的時間／位置可參考 [VTTCue](https://developer.mozilla.org/en-US/docs/Web/API/VTTCue)；ASS 座標與缺字型的處理屬專用渲染驗收，不能直接假設一般 cue 控制相同。

時間校正按「該影片＋該字幕來源」保存，不影響其他影片；資料夾自身可攜記錄保存 `SubtitlePrefs`，觀看進度不恢復。`details.subtitles` 保存匯入副本的相對引用，外部臨時來源不自動匯入。視窗尺寸／捲動先存本機，畫面樣式可有共用預設再明確覆寫；契約見 `shared/explorer.ts`，原影片／字幕不修改。

## 驗收

C-85 已採上述格式分期、字幕時間／位置與逐片保存、外部字幕臨時／明確匯入、續播選擇曾為基線，現已移除；接續播放由播放生命週期章節持有。來源識別／字幕偏好沿用現有版本契約、快捷鍵與失效例子；多音軌／內嵌字幕依相容性階段再做。ESC 一次先退出最上層／播放器全螢幕，不連帶退出工作區放大。

後續受控樣本需涵蓋大小檔、拖曳定位、音訊、切換影片釋放、無權限／檔案搬移、只有圖片／沒有影片、未知檔案不執行、格式不支援與原始檔不變。字幕另驗證拖入／失敗保留／亂碼、不同影片與來源不串設定、正負延遲及重設、seek／倍速／暫停／重播、窗寬／全螢幕定位與雙重字幕排除；ASS 等到對應階段補排版／字型樣本。只按修改範圍選相關 runner；本次文件整理未重跑產品測試，既有受控驗證僅供下方歷史追溯。

## 影片佇列展示

新版共用大視窗的影片佇列，在「目前資料夾」標題同列右側新增展示模式切換，保留現有清單並增加圖片模式。圖片模式以影片縮圖呈現所有項目，不是把影片佇列改為圖片檔案；選取、排序、同來源範圍與播放生命週期不因展示切換而改變。

每次開啟檢視器預設清單模式；圖片模式只常駐縮圖與選取標記，完整檔名透過 Hover／鍵盤聚焦提示及可存取名稱提供。展示方式在當次檢視開合佇列時保留，不新增跨次偏好。縮圖按需載入，失敗有可辨識佔位，不啟動多個影片播放實例；切換展示不重建播放器、不換片或重設進度。佇列整體的預設收合與過渡仍依 [工作區](WORKSPACE_REVISION.md#大視窗與同資料夾佇列)。
