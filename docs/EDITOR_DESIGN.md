# CELL 編輯器

本頁持有模板編輯與編輯器內的方案管理行為；CELL 種類只列在 [CELL_CATALOG](CELL_CATALOG.md)，瀏覽時的 CARD 工具列與方案切換由 [工作區](WORKSPACE_REVISION.md) 持有。實作入口：[Editor](../src/Editor.tsx)、[Card](../src/Card.tsx)、[shared/layouts](../shared/layouts.ts)。

## 資料與畫布

左側組件／欄位 → 中央單筆模板 → 右側組件設定。拖入建立組件實例，不複製某資料夾的值。模板用版本化模型保存 ID、類型、attributeId、格線／尺寸及受支援樣式，不保存 React 或第三方 library 物件。

CARD 專案方案與單一資料夾指定既有方案共用穩定方案身分；漫畫資訊等內容模板共用編輯能力但版面分開。資料夾帶自己的值，由目的專案版面顯示；單筆資料編輯只改值。指定方案見 [單一資料夾指定方案](#單一資料夾指定方案)，任意單筆畫布覆寫仍延後。

## 操作區配置

組件、畫布、組件設定採可讀寬度；空間不足時將設定區移至畫布下方，再於窄視窗改成縱向排列，不把兩側表單壓窄。

新增欄位以同一表單連接名稱 → 型別 → 新增；新增後出現在「專案欄位」，可點擊或拖入。建立定義不寫入假資料。

組件區分「基礎組件」與「專案欄位」，來源及使用次數見 [組件與欄位區](#組件與欄位區)。新增資料型組件須先建立／選擇欄位，不從泛型文字按鈕暗中建立定義。

「引用資料夾既有欄位」放在組件區，預設收合，按共用／本專案私有分組；共用欄位有本專案覆寫時另標示。引用時保留 attributeId，不複製值，不列其他專案私有欄位；有型別衝突的來源暫停引用。組件設定保留同型別欄位綁定與清楚的位置／尺寸標籤。

## 已確認互動與現行基線

- 保留 react-grid-layout 作格線拖放／調整尺寸引擎。固定邏輯格線，窄視窗減少每列筆數或換行；不能裁掉內容。
- 預設碰撞推開；沒有合法空間就拒絕並提示，不越界。不預設允許重疊／圖層，任意 CSS／腳本未納入。
- 新增分隔線組件；Delete 移除目前選取的組件，輸入框／選單輸入與中文組字不攔截，支援復原／重做。
- 圖片是選用組件，可新增多個獨立圖片位置；保存版面後在資料夾設定的「圖片」頁分別選圖／匯入，沒有設定可留空。不為所有資料夾建立必填圖片欄位。
- 支援選取、刪除、位置／尺寸數值輸入、真實資料夾預覽、取消、未保存保護與多步復原／重做。空值用佔位，不寫假資料；保存成功即套用。
- 新專案先有可用模板。文字與背景色是目前基本樣式，背景預設透明；格線數／限制以 shared 驗證與 Editor 為準，不當成永久產品尺寸。
- 字級、粗細、對齊、內距、邊框、圖片裁切、自訂色碼等是已確認的可擴充方向，未交付細節仍需分期，不宣稱整套設定均已存在。

改動時驗證涉及的拖入／碰撞／尺寸／保存／取消及真實資料綁定；共用引擎變更才補其他模板，不每次重跑所有媒體。原驗收例子與待選細節保存在 [原稿](history/agent-docs-before-cleanup.md#editor-design)。

## 組件與方案管理

以下為已核定規則；交付差距／待查收見 [當前工作](WORK_ITEMS.md)，不從本頁日期推定完成。方案管理只適用卡片，漫畫資訊模板沿用共用編輯能力；組件與欄位型別契約集中 [CELL 目錄](CELL_CATALOG.md#新增組件與型別)。

### 組件與欄位區

- 將「已有資料／尚無資料」合併為「專案欄位」，不因某資料夾是否填值而分區。項目顯示名稱、型別、共用／本專案私有／有私有覆寫，以及目前版面的使用次數；是否有值由中央真實資料夾預覽呈現。
- 保留預設收合的「引用資料夾既有欄位」，表示尚未加入本專案配置的來源，沿用原欄位身分及共用／私有規則。
- 左側區名簡化為「組件」，移除常駐的「點擊或拖入畫布，再到右側調整。」說明；點擊新增與拖曳功能保留。空白畫布提供「加入第一個組件」入口。
- 基礎組件與資料型別使用 CELL 目錄的契約；容器／群組的延後方向也由該目錄持有。

### 方案管理

此項是版面方案的新增、修改、複製及刪除；不將先前誤解為組件／欄位資料刪除的提案納入範圍。CARD 與漫畫仍共用編輯能力、版面分開，不因本項將 CARD 方案管理擴展為漫畫多方案。

- 編輯器上方以「方案 SELECT → ＋新增方案 → ⋯」集中管理；⋯ 提供複製、重新命名、刪除。右側保留取消與「儲存變更」，移除「另存為新方案（保留原方案）」勾選框。
- 新增方案需命名並建立空白畫布；複製以目前畫布（包含尚未保存的畫布調整）建立副本再命名，保留原方案。名稱不可重複。
- 新增、改名、刪除與畫布調整先留在編輯草稿，按「儲存變更」才正式生效並套用目前選擇的方案；取消可放棄本次全部調整。保存失敗保留草稿供重試。
- 刪除只移除方案版面，保留欄位定義、資料夾值及圖片資產；刪除目前方案後切換到另一現有方案，清楚顯示接替對象。至少保留一個方案，只剩一個時停用刪除並說明原因。
- 切換方案遇到未保存的畫布修改時，提供「保存後切換／捨棄／繼續編輯」；已存在的未保存保護同樣適用關閉及取消。
- 復原／重做使用上方工具列的一組小圖示，與方案操作分組；Hover／鍵盤聚焦提示名稱及快捷鍵，沒有可用紀錄時停用。保留多步歷史，讓尚未保存的刪除等編輯可復原。

### 方案工具列對齊

方案 SELECT、新增方案與更多按鈕統一控制高度、底線對齊及間距，標籤不推歪相鄰按鈕；長名稱可省略並查看完整名稱，窄視窗採有序換行。復原／重做依下節在上方工具列分組，方案及草稿語意保持上述規則；驗收需含三主題與不同語系。使用者圖 1 的未對齊問題留在工作清單追蹤。

### 工具列與拖曳呈現

- 畫面分為上方工具列及下方實際編輯區。工具列集中儲存／取消退出、方案與復原／重做，正常寬度盡量同列；窄視窗可按職責分組換行，不裁切或移除功能。下方維持組件、畫布及設定區，移除多餘說明。
- 拖曳組件的 Ghost Image 僅呈現該組件／來源項目，不包含上方標題、工具列或其他頁面內容；原生抓取點依滑鼠在來源內的位置計算，畫布拖曳以格線局部座標處理，涵蓋捲動與縮放；驗收從組件庫拖入及畫布內拖動，保持既有碰撞、尺寸與復原功能。

### 單一資料夾指定方案

2026-10-28 使用者採用推薦：首階段讓單一資料夾指定目前專案的既有版面方案，可恢復跟隨專案預設；不在本階段增加任意單筆畫布覆寫。此選擇只影響目前專案的顯示，不複製或改動共用欄位值。指定保存於本專案 folderLayouts，以 folderId 參照既有方案；清除即跟隨專案。刪除方案時移除其指定，失效參照回退專案版面；跨專案不搬用原專案指定，不影響欄位值與圖片。可攜 schemaVersion 維持 1，不遷移實際收藏。

資料夾設定中，此控制與實際欄位填值區使用分隔線或明確分區區別。SELECT 提供可明確選取的「遵循通用設定（此專案版面）」作為預設，不只靠空白 placeholder／清除按鈕表達繼承；遵循時不固定複製當下方案 ID，專案方案改變後持續跟隨。

### 自訂欄位刪除

提供實際刪除自訂欄位及其資料的管理動作，與「移除組件」只改版面明確區分。欄位身分依 attributeId 判斷，不把同名欄位當成同一欄位。

- 刪除前先預覽受影響的欄位數，另列資料夾數、欄位值筆數及方案／表格／漫畫版面／常用搜尋等引用數，分清計數單位；有其他專案共用時列出受影響專案。未填值不算一筆已有資料，0 與 false 是有效值，不可漏算。
- 使用者看到影響數量及範圍並確認後才刪除，即使沒有引用也需確認；取消不寫入。確認綁定預覽指紋，期間資料或引用變更需重看預覽。
- 刪除範圍中的欄位配置、值與引用需一致處理，不留下失效引用或自動綁到其他同名欄位。離線／未納入的資料不得宣稱已刪除；只顯示可證明範圍的數量及限制。引用此欄位的組件與整條常用搜尋一併移除，避免刪掉搜尋條件後意外擴大結果；預覽明示數量。已驗證的原位置備份獨立去除舊引用，復原副本留在樹外；未連結專案私有值及無法解析的無關舊查詢保留並列限制，疑似目標引用無法辨識時拒絕執行。
- 共用值／私有覆寫、受管資料所有權、備份與失敗復原依 [儲存安全](STORAGE_OPTIONS.md#清理與範圍) 處理；不刪除原始媒體或與欄位無關的資料。
