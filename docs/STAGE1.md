## 範圍

- 全域列：Logo／首頁、側欄顯隱、搜尋範圍與入口、自訂最小化／最大化還原／關閉。TABLE 導覽第二階段，不放全域列。
- 首頁：新增、重新連結、最近新增與問題專案；開啟既有專案、回首頁不退出連結。
- 側欄：群組新增／改名／刪除／收合、選單或拖放移動、收藏、最近、獨立捲動、調寬／收起。
- 搜尋先接名稱／路徑，範圍當前／全部已連結；未開預設全部，明示完整 key/value 第二階段。
- 接既有 CARD／編輯／詳情／復原／清理，保留受控 IPC 與草稿提示。不改可攜 schema、不新增套件。

## 本機 UI 契約

userData/workspace-ui.json，schemaVersion 1：群組 ID／名稱／收合、專案 ID 的分類／收藏／新增順序、側欄寬／顯隱與固定區收合。與可攜資料分開，本階段群組尚無跨設備匯出；既有專案按原連結順序初始化，不編造過去新增日期。

- 每專案一個自訂分類或未分類，收藏獨立。採可調 UI-R03：最近只列未分類且未收藏，按新增順序，不按最近使用。
- 刪群組移至未分類，收藏保留；重連同 ID 可恢復本機分類。
- main 驗證命令及引用、排隊保存並沿用可恢復寫入。失敗不回報成功；損壞原檔保留、提示不能保存，不靜默覆寫。
- 視窗 IPC 保留忙碌／未保存關閉攔截；renderer 無任意讀檔／程序能力。

## 查收條件

1. 空白 userData 顯示首頁；新增／重連／開啟／返回首頁可用，失效根有處理入口。
2. 群組、收藏、移動、收合及欄寬立即更新且重載一致；媒體與可攜資料不因側欄操作改變。
3. 最近派生正確；重名、未知 ID、非法命令與寫入失敗有明確結果。
4. 基本搜尋範圍正確，命中可開啟來源；不假裝完整查詢已實作。
5. 視窗控制／未保存攔截正常，800px 無整頁水平溢出；側欄滑鼠／鍵盤可調。
6. 僅受控 .test-output/ 與隔離 userData；交截圖、操作步驟及實際驗證後停止查收。

只跑新增本機設定測試、第一階段 Electron smoke、型別／build；未改可攜演算法不例行重跑效能與全套資料測試，有具體風險才追加。
