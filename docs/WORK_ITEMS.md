# 工作清單與問題追蹤

狀態：`待設計`、`待實作`、`進行中`、`待驗證`、`完成`、`受阻`。優先順序是建議；尚未執行的項目不得標成完成。每項開始前先確認使用者最新要求及未提交變更。

## 工作項目記錄格式

開始或結束工作時，可在相關 ID 下增加：`決策來源`、`變更檔案`、`驗證證據`、`剩餘問題`。具體執行過程追加到 [DEV_LOG.md](DEV_LOG.md)。若拆分工作，保留原 ID 並給子項新 ID，避免完成狀態含糊。
