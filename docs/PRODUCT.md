# 產品範圍

Windows 優先的本機資料夾檢視器。此頁維護產品邊界；互動細節由下列主文件持有。使用者最新指示優先，核定需求與實作完成／使用者查收是不同狀態。

## 已確認方向

- 以專案連結資料夾，提供 CARD／TABLE／TREE；LIST 就是 TABLE，沒有第四種模式。只檢視，不為瀏覽搬移或刪除原始資料。
- 每個受管資料夾保存可攜記錄與資產，跨設備復原不依賴本機資料庫或舊絕對路徑。巢狀專案可重疊；值預設共用，私有覆寫須顯式建立；目的專案決定版面。身分與缺值語意見 [資料模型](FOLDER_PROJECT_MODEL.md)。
- 遊戲 ROOT 是保護邊界；不能為一般導覽在遊戲內建立記錄。清理只移除明確受管資料，不移除遊戲或媒體原檔，詳見 [儲存安全](STORAGE_OPTIONS.md)。
- 視圖、模板、屬性值與來源資料分離；共用編輯能力，資料夾卡片、漫畫資訊等版面分開。保存後畫面即時更新。
- 專案分類控制呈現，不改資料夾原值；有可靠不符證據才提示，仍可檢視。缺失／損壞記錄與保護邊界的導覽限制另依工作區規則。
- 圖片、影片、音樂、其他四種舊分類以共用媒體頁相容讀取，新建入口只保留媒體、漫畫及遊戲；舊專案需明確預覽確認才轉換。圖片／文件來源清單、跨專案影音佇列與轉換安全由 [統一媒體工作區](WORKSPACE_REVISION.md#統一媒體工作區) 持有，實作差距依工作清單；不代表已授權批次轉換真實收藏。
- Mac／ChatGPT 等舊風格圖仍是預覽；已採用深色、霧白玻璃與暖紙三套主題及系統字型，規則見 [共用 UI](UI_RULES.md)。品牌與專屬字型仍延後，不因舊線稿重新設計全站。

## 範圍之外／後續

音樂與跨專案影音播放已有實作，未完成互動見 [工作清單](WORK_ITEMS.md#最新回饋)；PDF／ZIP／CBZ 已有唯讀能力，限制見 [文件檢視器](DOCUMENT_VIEWER_DESIGN.md)。無專案通用檢視、更多解碼器與來源等，依 [OPEN_DECISIONS](OPEN_DECISIONS.md) 另行授權。不要把設計候選、自動執行任意腳本、雲端同步或批量網路抓取推定為當前需求。原始決策理由按 ID 查 [DECISIONS](DECISIONS.md)。
