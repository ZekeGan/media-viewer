# POC 低保真文字線框

> 歷史設計／交付紀錄：保留原時點的範圍、提案與驗證，不例行追加，不作每輪前置檢查；當前入口見 [文件索引](../README.md)、[待查收](../WORK_ITEMS.md)。舊「待審／未實作」及完成測試數不代表現在狀態，亦不取代本輪驗證。


整理日期：2026-10-25。依[POC 階段設計書](POC_DESIGN_PACKAGE.md)及已核定方向繪製；**這是資訊與互動草案，不是視覺定稿或現有程式畫面**。Windows 桌面版先用 Mantine 的一般控制項；顏色、字體、具體尺寸與圖示稍後決定。`[ ]` 表示控制項，`(...)` 表示狀態／資料。

## 畫面關係

```text
W-01 專案入口 → W-02 新建／掃描 → W-03 資料夾列表 ↔ W-04 單筆側欄
                                      ├→ W-05 CELL 編輯器 → 返回列表
                                      ├→ W-06 專案設定 → 返回列表／重新掃描
                                      ├→ W-07 問題與重新連結 → 返回列表
                                      └→ W-08 儲存資料清理 → 結果／返回列表
```

POC 只有平面資料夾列表。根是第 1 層；媒體分類是專案設定，不因掃描寫入資料夾。W-04、W-08 可以是側欄或對話框，W-07 可是集中面板；此處先畫**操作位置與狀態**，不預設最終路由。

## W-01 專案入口／切換

```text
┌ Media Viewer ─────────────────────────────────────────────┐
│ [新增專案]  [重新連結既有專案]                             │
│                                                            │
│ 我的專案                                                   │
│ ┌ 漫畫專案  /P1  [開啟] [更多] ┐  ┌ 相簿專案 /P2 [開啟] ┐ │
│ │ 深度：1 至 2 層  (上次掃描)   │  │ (路徑失效／待連結)   │ │
│ └──────────────────────────────┘  └──────────────────────┘ │
│ (沒有專案時：選資料夾建立第一個專案)                        │
└────────────────────────────────────────────────────────────┘
```

- **操作**：新增到 W-02；開啟到 W-03；失效根或新設備重新連結到 W-07。專案可同根或巢狀，以 project ID 區分。
- **狀態**：顯示可用、路徑失效、掃描有問題；最近使用順序可由本機保存，不當可攜權威。

## W-02 建立專案／首次掃描

```text
┌ 新建專案 ───────────────────────────────────────────────────┐
│ 名稱 [漫畫專案________]  根資料夾 [/P1________] [選擇...]  │
│ 媒體分類 [漫畫 v]  （只影響此專案的顯示／後續來源）         │
│ 顯示深度  (●)第 1 至 [2] 層   ( )只顯示第 [3] 層          │
│ 提示：根資料夾是第 1 層；只顯示第 3 層仍走訪父層。       │
│ [建立並掃描] [取消]                                        │
│ ── 掃描中 ──────────────────────────────────────────────── │
│ 已掃 35／(總數未知)  已建記錄 31  錯誤 2  [取消掃描]       │
│ (不能存取的路徑和原因可展開；掃描中止後可續掃／核對)       │
└────────────────────────────────────────────────────────────┘
```

- **操作**：成功進 W-03；部分錯誤可繼續看已掃結果，從 W-07 重試。預設版面建立後就可用。
- **邊界**：不跟隨 junction／符號連結；唯讀可讀現有記錄，新建失敗要說明。資料目錄不列為媒體資料夾。

## W-03 資料夾列表（POC 主畫面）

```text
┌ [專案 v] 漫畫專案 ──────────────────────────────────────────┐
│ [搜尋名稱或路徑________] [重新掃描] [CELL 編輯器] [設定]   │
│ 路徑：/P1   模式：第 1 至 2 層   共 126 筆   [問題 2]     │
│ 排序 [名稱 v]   每列 [2 v]   每頁 [100 v]                 │
│ ┌ A ───────────────────────┐ ┌ B ───────────────────────┐  │
│ │ 名稱 A                   │ │ 名稱 B                   │  │
│ │ /P1/A                    │ │ /P1/B                    │  │
│ │ 自訂文字：作品 A         │ │ 自訂文字：(空白)         │  │
│ │ [開啟資料夾] [詳情／編輯] │ │ [開啟資料夾] [詳情／編輯] │  │
│ └──────────────────────────┘ └──────────────────────────┘  │
│ (其餘卡片依目前專案 CELL 模板呈現；有問題者顯示狀態)      │
│ [上一頁]  第 1／2 頁  [下一頁]                              │
└────────────────────────────────────────────────────────────┘
```

- **操作**：詳情到 W-04；編輯器到 W-05；設定到 W-06；問題／重新連結到 W-07；清理從 W-04 或設定進 W-08。
- **驗證**：系統名稱／目前路徑是真實掃描值；同模板對不同資料夾呈現不同文字。保存單筆值或模板後列表即時更新；翻頁穩定、不重複漏項。POC 搜尋限名稱／路徑子字串。
- **邊界**：缺值只留空或顯示編輯佔位，不寫回；分類不符只有明確內容類型／可信來源才提示，否則「未判定」。窄視窗減列數，不裁切卡片。

## W-04 單筆資料詳情／編輯側欄

```text
┌ 列表 ───────────────┬ A 的資料夾詳情 ─────────────────────┐
│ (W-03 保持可見)      │ 系統名稱 A  目前路徑 /P1/A          │
│                     │ 記錄 ID：folder-a...  狀態：正常     │
│                     │ 自訂文字（共用值，其他引用專案可見）│
│                     │ [作品 A________________________]    │
│                     │ 自訂圖片 [選擇並複製圖片] (預覽)     │
│                     │ 其他已存屬性／來源：[展開]          │
│                     │ [保存] [取消]                        │
│                     │ [清理這筆本程式資料 → W-08]         │
└─────────────────────┴──────────────────────────────────────┘
```

- **操作**：改文字／附圖成功後 W-03 立即更新；失敗保留編輯內容並說明，不顯示「已保存」。開啟資料夾使用目前路徑。
- **資料分離**：此處編輯 `A` 自身的值，不調整專案模板；`B` 不受影響。專案私有覆寫是已核定能力，但 POC 最小演練只驗證共用文字；詳情仍須能顯示搬入資料夾的原始欄位。

## W-05 CELL 積木編輯器（POC 核心畫面）

```text
┌ 編輯「漫畫專案」卡片 ───── [復原] [重做] [取消] [保存] ─────┐
│ 左：組件清單      中：卡片畫布／真實預覽      右：選中組件  │
│ ┌────────────┐  ┌─────────────────────────┐ ┌──────────┐ │
│ │資料        │  │ 預覽資料夾 [A v]        │ │ 類型：文字│ │
│ │[名稱]      │  │ ┌ 名稱 A ────────────┐  │ │ 綁定欄位 │ │
│ │[目前路徑]  │→ │ │ 自訂文字：作品 A   │  │ │ [CUSTOM...]││
│ │[自訂文字]  │  │ │ /P1/A              │  │ │ 文字色[...]││
│ │操作        │  │ │ [開啟資料夾]        │  │ │ 背景色[...]││
│ │[開啟資料夾]│  │ └────────────────────┘  │ │ x/y/w/h[...]││
│ └────────────┘  └─────────────────────────┘ └──────────┘ │
│ 拖入 → 選取 → 綁定／移動／縮放 → 切換預覽 [A][B]          │
│ (未保存變更提示；碰撞推開，無空間拒絕並顯示原因)           │
└────────────────────────────────────────────────────────────┘
```

- **核心操作**：左側拖入「名稱、路徑、自訂文字、開啟按鈕」四種組件；中央拖移、拉寬高；右側用穩定屬性 ID 綁定文字，改基本文字／背景色。按鈕動作只允許開啟目前資料夾。
- **真實預覽**：A 有文字、B 缺值；同一版面顯示不同真實內容。編輯的是**專案單筆卡片模板**，不是 A 的值。保存立即套用 W-03 全部卡片；取消維持原版面；重開仍在。
- **狀態**：無空間不重疊、不出畫布；未保存離開有提示。POC 每專案一份模板，圖片、NUMBER、DATETIME、更多樣式及單筆版面覆寫留到 MVP 後再選。

## W-06 專案設定

```text
┌ 漫畫專案／設定 ─────────────────────────────────────────────┐
│ 專案名稱 [漫畫專案____]  分類 [漫畫 v]                    │
│ 根資料夾 /P1  [重新連結 → W-07]                            │
│ 深度 (●)第 1 至 [2] 層  ( )只顯示第 [3] 層                 │
│ 列表 每列 [2]  每頁 [100]  排序 [名稱 v]                  │
│ 卡片模板 [開啟 CELL 編輯器 → W-05]                         │
│ (分類只決定此專案顯示，不寫入資料夾記錄)                   │
│ [保存並更新列表] [取消]                                    │
│ [儲存資料清理 → W-08]                                      │
└────────────────────────────────────────────────────────────┘
```

- **操作**：保存即時更新 W-03；深度變更顯示需要重新掃描的進度；每列／每頁筆數有明確界限，窄視窗可自動減列數。
- **邊界**：同一根可有多個 project ID；改專案分類不改資料夾內容類型。完整搜尋別名、保存搜尋等控制留到 MVP。

## W-07 問題、復原與重新連結

```text
┌ 問題與復原 ─────────────────────────────────────────────────┐
│ 專案 /P1：路徑失效 [選擇新位置] [重新掃描]               │
│ A：找到原 folder ID 於 /P2/A [確認重新連結]               │
│ B：唯讀 [查看原值] [重試寫入]                              │
│ C：記錄損壞 [查看原因] [從可用備份恢復]                    │
│ D/E：重複 ID，兩筆暫停寫入 [搬移重連] [其中一筆是副本]    │
│ 本機索引落後 [從可攜記錄重建]                              │
│ 掃描略過：無權限 2、連結 1 [展開路徑與原因]               │
│ [返回列表]                                               │
└────────────────────────────────────────────────────────────┘
```

- **操作**：每項只提供與其狀態相符的下一步。搬移靠記錄 ID；兩份同 ID 並存先停止寫入，副本確認後另配新 ID 並保留值。
- **安全結果**：損壞原檔及寫入衝突雙方資料都保留；索引可從可攜檔重建；離線或未連結不假裝已清理。單筆徹底清理後搬到另一專案，依 C-66 作新資料夾，不顯示身分不明。

## W-08 清理預覽與結果

```text
┌ 清理本程式資料 ────────────────────────────────────────────┐
│ 範圍 (●)此資料夾 A  ( )此專案私有資料* ( )全部已連結資料│
│ 找到：記錄 1、圖片 1、專案設定 0、本機索引項 1           │
│ 不涵蓋：離線／未連結的副本、無權限路徑 [查看清單]         │
│ 原始漫畫／遊戲／影片等媒體檔案：不清理                   │
│ 個別清理後：(●)停止記錄此項  ( )清除後重新開始            │
│ [檢視明細／備份路徑] [確認清理] [取消]                    │
│ ── 完成後 ─────────────────────────────────────────────── │
│ 成功 1  失敗 0  未涵蓋 2  [重試失敗項] [返回列表]        │
└────────────────────────────────────────────────────────────┘
```

- **操作**：從 W-04 預設「此資料夾」；從 W-06 可選全部已連結資料。`*` 沒有私有覆寫時停用「此專案私有資料」；POC 演練只需共用值。先預覽、再明確確認；顯示逐項結果及失敗重試。
- **限制**：只刪能驗證屬於本程式的記錄、資產與索引；不碰原始媒體。停用記錄後原位置重掃不再建立；徹底清理後搬到另一專案則作新資料夾，給新 ID 與空白自訂值。

## 全畫面共同狀態與審核點

| 狀態 | 最小呈現規則 |
| --- | --- |
| 載入／掃描中 | 顯示進度與可取消；已成功寫入的記錄要可核對，下次可續掃。 |
| 空專案／零搜尋結果 | 說明目前根與深度或搜尋條件，提供改設定／清除搜尋入口，不生成假資料。 |
| 未保存變更 | W-04、W-05、W-06 明確標示；離開時可取消、保留或返回。 |
| 錯誤與部分成功 | 保留已成功內容，清楚指出失敗項、原因及下一步；不顯示為全部完成。 |
| 可攜內容與本機索引 | 使用者看到值和復原狀態；不把資料檔當普通媒體顯示。 |

本線框對應設計書 A-01 至 A-14；POC 實作前需審核各畫面**操作能否完成閉環**，並以 C-66 驗收清理後原位停用、搬入其他專案視為新資料夾。視覺風格、精確尺寸、MVP 型別與來源網站不在此輪定案。
