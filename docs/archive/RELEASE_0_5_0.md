## 本輪行為

- 側欄專案拖曳排序／跨群組移動及插入提示；一般狀態隱藏專案動作，Hover 或鍵盤操作時可用。首頁及整合設定在 Logo 下方同列，新增專案在底部且不使用強調色。
- 整合設定包含目前專案名稱／分類及全域重新連結、舊匯入與清理；CARD 的方案與顯示設定移至中央工具列，資料夾設定固定最右。
- CARD 多層可選全部／第 1 至 N 層，平鋪 ROOT 及後代；單層 N 為起始層，之後逐層進入。TREE 保留全階層，TABLE 從 ROOT 直接子層開始。CARD 層數及密度不改其他模式。
- CARD 多層／TREE 雙擊只更新右側；CARD 單層／TABLE 雙擊進子層並更新右側。主程序先讀取有效記錄與檢查遊戲邊界，缺記錄／受保護／損壞時拒絕且不自動建檔。遊戲 ROOT 自身可展示。
- 中央與右側內容獨立，首次預設顯示 ROOT；本機保存內容對象、顯隱及各模式位置。X 與工具列開關同步，右鍵另開設定 Drawer；通知在右下。
- CARD 方案可修改／另存，僅保存 CELL 內容及樣式；密度／層數另存。新 CELL 預設透明，符合舊原始預設的外觀在顯示時轉透明，不批次改寫自訂色。
- 建立順序為名稱 → 分類 → 選資料夾 → 群組 → 完成。選擇只取得短期 token，完成前不建檔；新專案預設多層＋全部及未分類。
- 遊戲內容恢復無邊框封面／右上更換小 ICON、自訂操作、欄位 TABLE；封面可匯入，取消不修改記錄。影片區保留播放器與下方影片列，字幕等設定置播放器內跳窗。
- PNG／JPEG／WebP／GIF／BMP／AVIF／ICO 的原圖與縮圖已用受控檔案實際解碼。原生解碼失敗時以既有 Chromium 備援；縮圖序列處理、同圖合併、暫存置換及損壞快取重建，失敗可回退原圖。原圖不覆寫。
- Windows 縮放產生的小數欄寬可重現「瀏覽設定不合法」；現於前後端正規化為整數，仍拒絕越界／非法設定並保留舊值。使用者原始觸發步驟未提供，不將所有同名錯誤都歸因此路徑。
- TREE 初始視野依 Dagre 已知尺寸與容器預算，避免首次選取才自動置中造成雙擊偏移；之後選取不重算布局，縮放／平移仍使用 React Flow。
