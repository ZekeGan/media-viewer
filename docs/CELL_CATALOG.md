# CELL 目錄

此頁區分現行契約與候選；共用編輯行為見 [EDITOR_DESIGN](EDITOR_DESIGN.md)。值、版面及受控動作分開；舊 DataType 不作目標範式。

## 現行契約

[CellKind](../shared/model.ts) 與 runtime 驗證是程式真相，新增種類需同步 renderer／驗證／可攜相容性。

| kind | 用途 |
| --- | --- |
| name／path | 目前資料夾系統名稱／路徑，不把舊設備路徑當可攜原值 |
| field-text | 依 attributeId 顯示文字 |
| field-tags | 多值標籤 |
| field-number | 數字 |
| field-date | 日期時間 |
| field-boolean／field-enum／field-url／field-date-only | 是／否、單選、網址、純日期 |
| static-text／spacer／system-info | 固定文字、占位間距、系統資訊 |
| image | 選用的獨立圖片組件；每個位置可各自選圖，空白不強制填寫 |
| divider | 分隔線，沿用組件尺寸／文字色 |
| open-folder | 經 main 驗證後開啟目前資料夾 |

缺 key 可顯示預設，但不寫回資料夾、不成為搜尋真值；搬入專案的欄位身分不可只按相同 alias 合併。

遊戲的 EXE／資料夾按鈕已有專屬工具列與獨立目標／參數，見 [遊戲](GAME_VIEWER_DESIGN.md)；不因此擴大所有 CARD CELL 的動作權限。

## 新增組件與型別

2026-10-28 使用者確認新增以下三種基礎組件與四種欄位型別；已接入 CellKind、編輯器、資料欄位、搜尋／排序與可攜保存；schemaVersion 維持 1。

| 基礎組件 | 目標行為 |
| --- | --- |
| 固定文字 | 文字保存在版面，用於標題／說明；不建立資料欄位或複製到各資料夾 |
| 空白間距 | 可調寬高並實際占用格線，抵抗自動向上排列；編輯時顯示虛線，瀏覽時透明 |
| 系統資訊 | 提供分類、檔案數、容量等系統／衍生資訊，使用既有索引或快取；未取得或未計算需明示，不為渲染卡片逐筆同步掃描 |

| 欄位型別 | 目標行為 |
| --- | --- |
| 是／否 | 支援未填、是、否；未知不能當作 false |
| 單選 | 用於狀態等受控選項，選項可管理，避免自由輸入造成名稱不一致 |
| 網址 | 驗證網址，可顯示自訂文字並透過受控入口開啟連結，不擴大為任意系統命令 |
| 日期 | 與日期時間分開，用於發售日／購入日等，不強迫補時間或時區 |

新增型別一併支援 CELL 顯示、資料夾設定編輯、搜尋／排序、值驗證、可攜保存及舊資料相容，不只增加選單。空值不寫假資料；型別儲存與查詢契約由 shared/fields.ts 與驗證持有，未因此授權批次遷移實際收藏。

評分先作為數字欄位的顯示方式，多行長文字先作為文字組件的呈現設定；不另新增獨立資料型別。操作區與方案管理見 [編輯器](EDITOR_DESIGN.md#組件與方案管理)。

## 後續計畫與保留候選

容器／群組已確認放入後續計畫，需先細化巢狀拖曳、尺寸與選取規則，再另行實作，不併入上述首批基礎組件。

尚未核定的擴充包含富文字、更多衍生值（如時長）、更完整數值格式與單位、日期精度／時區等，需要逐項規格及排程。來源日期不能與系統／購買時間混用；只有年／年月的資料不能硬補日期。

候選的來源、renderer、格式／空值／樣式及操作需各自明確；衍生值標示計算狀態／更新時間，不阻塞基本列表。其他外部應用不得變成任意系統命令輸入。更完整例子見 [封存目錄](history/agent-docs-before-cleanup.md#cell-catalog)，不是本輪必做清單。

系統檔案數與容量採已開啟內容的直接檔案快取，顯示最後計算時間；未知顯示「尚未計算」，不在卡片渲染時掃描。網址只允許 HTTP(S)，拒絕內嵌帳密與系統命令；單選定義 1～100 個唯一非空選項，已不在選項內的舊值仍可讀取，寫入新值時驗證。純日期檢查真實曆日，是／否以 null 表未填並保留 false；未知舊型別原樣保留。入口 shared/fields.ts、src/folderStats.ts、tests/decided.test.ts。
