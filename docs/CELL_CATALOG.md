# CELL 資料顯示與操作目錄

整理日期：2026-10-25。**狀態：候選功能目錄，並非 MVP 必做清單；POC 的四種基本組件與驗收步驟見 [POC 階段設計書](POC_DESIGN_PACKAGE.md)。** cell 是專案版面的組件實例；它引用資料夾系統資訊或有型別屬性，亦可配置受控動作。資料值、顯示方式與動作定義分開；現有原型的 `DataType` 不是清單範式。

## 候選顯示資訊

| 類別 | 例子 | 資料來源與注意事項 |
| --- | --- | --- |
| 系統基本資訊 | 實際資料夾名稱、目前路徑、相對路徑、父資料夾、掃描層級 | 從目前掃描產生；不要把舊設備絕對路徑當成可攜值。POC 優先名稱與路徑。 |
| STRING／文字 | 自訂名稱、簡介、備註、來源連結 | 可為使用者填寫或來源匯入；換行、空值和長字串需有顯示規則。 |
| NUMBER | 評分、集數、時長、檔案大小、遊戲時數 | 數值與單位分開；如檔案大小與時長屬計算值，需標示來源及更新時間。 |
| DATETIME／DATE | 發行日、加入日、上次整理日、檔案修改時間 | 明確區分來源日期及系統時間；發行日可能只有年或年月，不能硬補日。 |
| BOOLEAN／狀態 | 已讀、已玩、已完成、稍後看 | 可用圖示、文字或徽章；未填不等於 false。 |
| 標籤／選項 | 類型、語言、平台、自訂標籤 | 多值與單值不同；來源標籤與手填標籤可並存。 |
| 圖片／封面 | 自訂圖、來源封面、資料夾中選定的圖片 | 原圖可攜、縮圖本機快取；畫面避免一次載入大量原圖。 |
| 衍生資訊 | 檔案數、子資料夾數、媒體數、容量 | 可能需要額外掃描；先顯示計算中／上次計算，不阻塞基本列表。 |
| 來源／連結 | 商品頁、畫廊頁、匯入來源、上次同步時間 | 提供可追溯性；不是所有外部來源都有相同欄位。 |

## 候選操作

| 操作 | 建議階段 | 限制／理由 |
| --- | --- | --- |
| 開啟目前資料夾 | POC | 已核定的第一個操作；傳給 Electron main 驗證後執行。 |
| 顯示在檔案總管、複製目前路徑 | MVP 候選 | 操作目前路徑，不改資料夾內容。Electron 提供開啟及顯示檔案的 shell 方法。[Electron shell 文件](https://www.electronjs.org/docs/latest/api/shell) |
| 開啟來源網址、編輯本筆值、重新掃描本筆 | MVP 候選 | URL 必須驗證協定；掃描與寫入顯示結果及錯誤。 |
| 切換已讀／完成、加入標籤 | MVP 候選 | 是資料寫入，需明確對應有型別欄位、可復原並即時更新搜尋。 |
| 啟動遊戲、呼叫外部應用、播放／閱讀 | 後續議題 | 路徑、參數與權限需逐類設計；不提供直接輸入任意系統命令的通用按鈕。 |

## 已確認分期原則與待選組件

- **POC**：展示真實資料夾名稱／目前路徑、預設版面與簡化積木編輯、開啟資料夾及一個基本文字欄位，以證明搬移、保存與即時顯示閉環；依 C-56。
- **MVP**：逐步增加其他有型別顯示與受控操作。NUMBER、DATE／DATETIME、BOOLEAN、標籤、圖片、來源連結只是候選，**哪些先做待使用者後續討論**，見 O-66。
- **後續**：媒體閱讀／播放、啟動遊戲、可編輯進階衍生統計；使用者要求先擱置閱讀／播放細節。

每個組件設定至少區分**資料來源、renderer、格式／樣式、空值顯示及操作**。例如 NUMBER 可選整數／小數與單位，DATE 可選格式和未知精度的顯示，按鈕只保存允許的動作型別與參數。專案改版面不改資料夾值；缺 key 顯示預設也不寫回資料夾。這些是後續設計例子，不代表已排定型別。
